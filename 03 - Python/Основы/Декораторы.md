# Декораторы

[[Основы]]

Декоратор принимает функцию или класс и возвращает обёрнутый объект. Синтаксис `@decorator` эквивалентен присваиванию `function = decorator(function)`.

Декораторы применяют для логирования, проверки прав, кеширования, метрик и повторных попыток. `functools.wraps` сохраняет имя и документацию исходной функции.

```python
# Оборачивает вызов функции и сохраняет её метаданные.
# Ожидаемо: перед результатом функции будет напечатано её имя.
from functools import wraps

def logged(function):
    @wraps(function)
    def wrapper(*args, **kwargs):
        print(f"call {function.__name__}")
        return function(*args, **kwargs)
    return wrapper
```
