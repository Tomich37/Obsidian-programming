# Генераторы и итераторы

[[Основы]]

Итератор — объект с методами `__iter__()` и `__next__()`. Он выдаёт элементы по одному и завершает обход исключением `StopIteration`.

Генератор — удобный способ создать итератор функцией с `yield` или generator expression. Он лениво сохраняет состояние между вызовами и не хранит всю последовательность в памяти.

```python
# Возвращает значения по одному и сохраняет состояние между yield.
# Ожидаемо: цикл напечатает 0, 1 и 4 без создания полного списка заранее.
def squares(limit):
    for value in range(limit):
        yield value * value

for item in squares(3):
    print(item)
```
