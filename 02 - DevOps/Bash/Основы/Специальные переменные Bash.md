# Специальные переменные bash

[[00 Основы Bash]]

Частые специальные переменные:
- `$?` - код возврата последней команды;
- `$$` - PID текущего shell;
- `$!` - PID последнего фонового процесса;
- `$@` - все аргументы скрипта отдельными словами;
- `$#` - количество аргументов;
- `$0` - имя скрипта;
- `$1`, `$2` - первый и второй аргумент.

Пример:
```bash
# Запускает команду, чтобы после нее посмотреть код возврата.
# Ожидаемо: true завершится с кодом 0.
true

# Показывает код возврата последней команды.
# Ожидаемо: 0 для успеха, не 0 для ошибки.
echo $?

# Показывает PID текущего shell.
# Ожидаемо: число процесса bash.
echo $$

# Запускает sleep в фоне.
# Ожидаемо: команда вернет управление сразу.
sleep 30 &

# Показывает PID последнего фонового процесса.
# Ожидаемо: PID процесса sleep.
echo $!
```

Короткий ответ:

Специальные переменные bash позволяют получить код возврата, PID shell, PID фонового процесса и аргументы скрипта.
