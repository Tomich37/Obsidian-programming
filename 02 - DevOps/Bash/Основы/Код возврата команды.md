# Как проверить код возврата команды

[[00 Основы Bash]]

Код возврата показывает, успешно ли завершилась команда.

Обычно:
- `0` - успех;
- любое другое число - ошибка.

Пример:
```bash
# Проверяет доступность файла.
# Ожидаемо: команда завершится с 0, если файл существует.
test -f /etc/passwd

# Показывает код возврата предыдущей команды.
# Ожидаемо: 0 если /etc/passwd есть, 1 если файла нет.
echo $?

# Выполняет правую команду только если левая успешна.
# Ожидаемо: echo выполнится только при существующем файле.
test -f /etc/passwd && echo "Файл есть"

# Выполняет правую команду только если левая завершилась ошибкой.
# Ожидаемо: echo выполнится только если файла нет.
test -f /no/such/file || echo "Файла нет"
```

Короткий ответ:

Код возврата хранится в `$?`. В shell-скриптах на нем строят проверки через `if`, `&&` и `||`.
