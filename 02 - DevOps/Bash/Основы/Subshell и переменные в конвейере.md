# Subshell и переменные в конвейере

[[00 Основы Bash]]

Команды в pipeline часто выполняются в отдельных subshell. Изменение переменной внутри такого процесса не меняет переменную родительского shell.

```bash
# Демонстрирует, что присваивание в правой части pipeline происходит в subshell.
# Ожидаемо: во многих версиях Bash будет напечатано 5, а не 10.
a=5; true | { true && a=10; }; echo "$a"

# Включает выполнение последней команды pipeline в текущем shell без job control.
# Ожидаемо: после включения lastpipe пример может напечатать 10 в неинтерактивном shell.
set +m; shopt -s lastpipe; a=5; true | { true && a=10; }; echo "$a"
```

Надёжнее не полагаться на изменение переменных внутри pipeline: использовать process substitution, временный файл, command substitution или явно читать результат.
