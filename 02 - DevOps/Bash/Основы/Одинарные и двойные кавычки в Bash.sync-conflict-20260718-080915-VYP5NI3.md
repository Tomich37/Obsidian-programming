# Одинарные и двойные кавычки в bash

[[00 Основы Bash]]

Одинарные кавычки `'...'` сохраняют текст почти буквально. Переменные внутри не раскрываются.

Двойные кавычки `"..."` сохраняют пробелы, но раскрывают переменные и подстановки.

Пример:
```bash
# Создает переменную NAME.
# Ожидаемо: в текущем shell появится переменная со значением world.
NAME="world"

# Одинарные кавычки не раскрывают переменную.
# Ожидаемо: будет напечатано Hello $NAME.
echo 'Hello $NAME'

# Двойные кавычки раскрывают переменную.
# Ожидаемо: будет напечатано Hello world.
echo "Hello $NAME"
```

Короткий ответ:

Одинарные кавычки почти все оставляют как текст, двойные позволяют раскрывать переменные, но защищают пробелы от разбиения.
