# Что такое POSIX

[[00 Основы Bash]]

`POSIX` - набор стандартов для Unix-like систем.

Он описывает:
- системные вызовы;
- поведение shell;
- базовые утилиты;
- файловые операции;
- модель процессов;
- права и сигналы.

Зачем нужен:

POSIX помогает писать программы и скрипты, которые будут работать предсказуемо в разных Unix-like системах: Linux, BSD, macOS.

Короткий ответ:

POSIX - это стандарт совместимости Unix-like систем. Он задает общие правила для API, shell и базовых утилит.
