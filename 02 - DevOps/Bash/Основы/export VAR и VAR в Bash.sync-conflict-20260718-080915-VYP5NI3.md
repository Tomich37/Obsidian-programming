# export VAR и VAR в bash

[[00 Основы Bash]]

`VAR=value` создает переменную только внутри текущей shell.

`export VAR=value` делает переменную переменной окружения. Тогда ее увидят дочерние процессы.

Пример:
```bash
# Создает обычную shell-переменную.
# Ожидаемо: текущий bash видит VAR, но дочерняя программа может ее не увидеть.
VAR="value"

# Экспортирует переменную в окружение дочерних процессов.
# Ожидаемо: запущенные из этой shell программы увидят VAR через environment.
export VAR="value"

# Показывает переменные окружения процесса.
# Ожидаемо: в выводе будет VAR=value, если переменная экспортирована.
env | grep '^VAR='
```

Короткий ответ:

`VAR=value` доступна текущему shell, а `export VAR=value` попадет в окружение программ, которые будут запущены из этого shell.
