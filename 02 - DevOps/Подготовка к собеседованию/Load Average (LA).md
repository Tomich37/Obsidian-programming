# Load Average

Load Average показывает среднее количество задач, которые:
- выполняются на CPU или готовы выполняться;
- находятся в непрерываемом ожидании `D`, чаще всего ожидают дисковый I/O.

Три значения — средняя нагрузка за 1, 5 и 15 минут. По ним виден тренд:
- первое больше третьего — нагрузка растёт;
- первое меньше третьего — нагрузка снижается;
- значения близки — нагрузка стабильна.

LA нужно сравнивать с количеством логических CPU. Для 8 CPU значение около 8 означает, что вычислительные ресурсы заняты, но очередь обычно невелика. Значение намного выше 8 означает очередь, однако причина может быть не только в CPU, но и в задачах состояния `D`.

LA `900` может быть допустим только для очень большой системы или специфической нагрузки. Проверять нужно число CPU, `r` и `b` в `vmstat`, `iowait`, состояние процессов и задержки приложения.

```bash
# Показывает Load Average за 1, 5 и 15 минут.
# Ожидаемо: три числа после load average.
uptime

# Показывает число доступных логических CPU.
# Ожидаемо: одно число, с которым можно грубо сравнить Load Average.
nproc

# Показывает очередь runnable-задач, заблокированные задачи, CPU и I/O каждую секунду.
# Ожидаемо: столбцы r, b, us, sy, id и wa для поиска причины высокого LA.
vmstat 1

# Показывает процессы в состояниях R и D с их командой и каналом ожидания.
# Ожидаемо: список задач, которые используют CPU или ожидают ресурс ядра.
ps -eo state,pid,ppid,wchan:32,comm | awk '$1 ~ /^[RD]/'
```

Коротко: Load Average — это не процент CPU, а среднее число выполняющихся, готовых и непрерываемо ожидающих задач. Три значения нужны для оценки динамики нагрузки.
