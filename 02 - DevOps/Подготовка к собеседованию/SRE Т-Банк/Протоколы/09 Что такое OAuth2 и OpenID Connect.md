# Что такое OAuth2 и OpenID Connect

[[00 Протоколы - вопросы]]

`OAuth2` - протокол авторизации. Он позволяет приложению получить ограниченный доступ к ресурсу от имени пользователя.

Пример:

Сервис получает право читать профиль пользователя, но не получает пароль пользователя.

Основные роли:
- Resource Owner - пользователь;
- Client - приложение;
- Authorization Server - сервер авторизации;
- Resource Server - API с ресурсами.

`OpenID Connect` - слой аутентификации поверх OAuth2.

Если коротко:
- OAuth2 отвечает за "что можно делать";
- OpenID Connect отвечает за "кто пользователь".

Короткий ответ:

OAuth2 - про выдачу прав доступа, OpenID Connect - про вход пользователя и подтверждение личности поверх OAuth2.
