# Что такое SSH

[[00 Протоколы - вопросы]]

`SSH` - защищенный протокол удаленного доступа к серверу.

Обычно работает на порту `22`.

Что дает SSH:
- удаленную консоль;
- шифрование трафика;
- аутентификацию по паролю или ключам;
- передачу файлов через `scp`/`sftp`;
- туннелирование портов.

Подключение:
```bash
ssh user@server
```

Ключевая аутентификация:
```bash
ssh-keygen
ssh-copy-id user@server
```

Как объяснить просто:

SSH - это способ безопасно открыть терминал на удаленном сервере. Все команды выполняются на сервере, а трафик между клиентом и сервером шифруется.
