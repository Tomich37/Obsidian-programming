# Что такое DNS

[[00 Протоколы - вопросы]]

`DNS` - система доменных имен. Она преобразует доменное имя в IP-адрес.

Пример:
```text
example.com -> 93.184.216.34
```

Зачем нужен:

Людям удобно помнить имена, а компьютеры работают с IP-адресами.

Основные типы записей:
- `A` - IPv4-адрес;
- `AAAA` - IPv6-адрес;
- `CNAME` - alias на другое имя;
- `MX` - почтовые серверы;
- `TXT` - текстовые данные, часто для проверок;
- `NS` - DNS-серверы зоны.

Проверка:
```bash
# Запрашивает DNS-записи домена.
# Ожидаемо: ANSWER SECTION с IP-адресом, TTL и DNS-сервером.
dig example.com

# Делает простой DNS-запрос имени.
# Ожидаемо: адрес DNS-сервера и найденные IP-адреса домена.
nslookup example.com
```

Короткий ответ:

DNS - это распределенная система, которая по имени домена возвращает нужные сетевые записи, чаще всего IP-адрес сервера.
