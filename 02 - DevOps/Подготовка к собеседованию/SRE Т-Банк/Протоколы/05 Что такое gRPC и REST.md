# Что такое gRPC и REST

[[00 Протоколы - вопросы]]

`REST` - архитектурный подход к API, где ресурсы доступны через URL, а действия выражаются HTTP-методами.

Пример:
```http
GET /users/10
POST /users
DELETE /users/10
```

Обычно данные передаются в JSON.

`gRPC` - RPC-фреймворк, где клиент вызывает методы удаленного сервиса как функции. Обычно использует HTTP/2 и Protocol Buffers.

Пример идеи:
```text
UserService.GetUser(id)
```

Сравнение:
- REST проще читать и отлаживать через `curl`;
- gRPC быстрее и строже по контракту;
- REST часто удобен для внешних API;
- gRPC часто удобен для внутреннего общения микросервисов.

Короткий ответ:

REST строится вокруг ресурсов и HTTP-методов. gRPC строится вокруг удаленных вызовов методов и строгого контракта через proto-файлы.
