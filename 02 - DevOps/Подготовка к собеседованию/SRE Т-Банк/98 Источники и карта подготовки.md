# Источники и карта подготовки

[[00 SRE Т-Банк]]

Точного публичного списка вопросов именно для SRE-собеседования в Т-Банк найти не удалось. Поэтому база собрана из трех групп:
- темы со скриншота: Linux, сети, базы данных, протоколы, криптография, файловые системы;
- типовые SRE/DevOps interview banks;
- официальные материалы Google SRE по SLI/SLO, мониторингу, error budget, troubleshooting и incident practices.

# Использованные источники

- Google SRE Book - Service Level Objectives: https://sre.google/sre-book/service-level-objectives/
- Google SRE Book - Monitoring Distributed Systems: https://sre.google/sre-book/monitoring-distributed-systems/
- Google SRE Book - Effective Troubleshooting: https://sre.google/sre-book/effective-troubleshooting/
- Google SRE Workbook - Alerting on SLOs: https://sre.google/workbook/alerting-on-slos/
- DevOps Exercises, разделы Linux/Networking/Databases/SRE: https://github.com/bregman-arie/devops-exercises
- Swfuse devops-interview, большой список вопросов по Linux, железу, Docker, Kubernetes, Terraform и AWS: https://github.com/Swfuse/devops-interview/blob/main/interview.md

# Что добавлено из Swfuse devops-interview

Добавлены и разнесены по текущей структуре не дословные копии, а переработанные шпаргалки:
- `Железо и удаленный доступ`: IPMI/BMC, KVM, просмотр железа, BIOS/UEFI, PXE, QEMU/KVM.
- `Bash и системные основы`: POSIX, export, специальные переменные, потоки, sudo, userspace/kernelspace, системные вызовы.
- `Kubernetes`: Service, Ingress, Job/CronJob, Namespace, PV/PVC/StorageClass, ConfigMap/Secret, API versions.
- `Terraform`: provider/resource/data source, tfstate, drift, import, lifecycle.
- `AWS`: Security Group, S3, Route53, EKS.
- `Docker`: образ/контейнер, Dockerfile, слои, volumes, network, диагностика, multi-stage, лимиты ресурсов.
- Точечные дополнения в `Linux`, `Протоколы` и `Файловые системы`.

# Как пользоваться

Если времени мало:
1. Пройти [[02 - DevOps/Linux/Linux|Linux]] и [[02 - DevOps/Сети/00 Сети|сети]].
2. Пройти [[02 - DevOps/SRE/Практики/00 SRE практики|практики SRE]].
3. Потом добрать [[05 - БД/Базы данных|базы данных]], [[02 - DevOps/Сети/Протоколы/00 Протоколы|протоколы]], [[02 - DevOps/Криптография/00 Криптография|криптографию]], [[02 - DevOps/Linux/Файловые системы/00 Файловые системы|файловые системы]], [[02 - DevOps/Docker/00 Docker|Docker]], [[02 - DevOps/Kubernetes/00 Kubernetes|Kubernetes]], [[02 - DevOps/Terraform/Terraform|Terraform]] и [[02 - DevOps/AWS/00 AWS|AWS]].

Если вопрос звучит как сценарий, отвечать по схеме:
```text
1. Симптом.
2. Что проверяю.
3. Какими командами/метриками.
4. Возможные причины.
5. Как безопасно исправлять.
```
