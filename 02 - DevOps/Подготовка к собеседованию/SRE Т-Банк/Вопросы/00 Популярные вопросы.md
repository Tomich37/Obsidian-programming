# Как готовиться

1. Сначала пройти вопросы с оценкой `9-5`, затем `4-2`.
2. Отвечать вслух без конспекта в течение 1-3 минут.
3. После ответа переходить по ссылке и сверять определение, механизм работы и команды диагностики.
4. Вопросы с оценкой `0` использовать для проверки глубины знаний и практического мышления.
