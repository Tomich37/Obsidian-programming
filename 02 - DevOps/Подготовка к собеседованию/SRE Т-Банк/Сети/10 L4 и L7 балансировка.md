# L4 и L7 балансировка

[[00 Сети - вопросы]]

`L4` балансировка работает на транспортном уровне: TCP/UDP.

Она смотрит в основном на:
- IP;
- порт;
- протокол.

Пример:

Балансировщик принимает TCP-соединение на `:443` и отправляет его на один из backend'ов.

`L7` балансировка работает на прикладном уровне, например HTTP.

Она может учитывать:
- Host header;
- URL path;
- HTTP headers;
- cookies;
- метод запроса.

Пример:
```text
/api -> backend-api
/static -> backend-static
```

Короткий ответ:

L4 балансирует соединения по TCP/UDP, L7 понимает прикладной протокол и может маршрутизировать по HTTP-пути, домену или заголовкам.
