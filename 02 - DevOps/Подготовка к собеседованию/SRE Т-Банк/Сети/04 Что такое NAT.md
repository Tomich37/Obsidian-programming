# Что такое NAT

[[00 Сети - вопросы]]

`NAT` - Network Address Translation, преобразование сетевых адресов.

Чаще всего NAT нужен, чтобы много устройств из локальной сети выходили в интернет через один внешний IP.

Пример:
```text
Ноутбук: 192.168.1.10
Телефон: 192.168.1.11
Роутер внутри: 192.168.1.1
Роутер снаружи: публичный IP
```

Когда ноутбук идет в интернет, роутер подменяет внутренний адрес на внешний и запоминает соответствие соединения. Когда приходит ответ, роутер понимает, какому внутреннему устройству его вернуть.

Виды:
- `SNAT` - меняется адрес источника;
- `DNAT` - меняется адрес назначения;
- `MASQUERADE` - частый вариант SNAT для динамического внешнего IP.

Короткий ответ:

NAT - это механизм, который подменяет IP-адреса в пакетах. Самый частый пример - домашний роутер, который выпускает всю локальную сеть в интернет через один внешний IP.
