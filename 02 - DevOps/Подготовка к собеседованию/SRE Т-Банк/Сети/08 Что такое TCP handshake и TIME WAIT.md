# Что такое TCP handshake и TIME WAIT

[[00 Сети - вопросы]]

TCP-соединение устанавливается через three-way handshake:
1. Клиент отправляет `SYN`.
2. Сервер отвечает `SYN-ACK`.
3. Клиент отправляет `ACK`.

После этого стороны могут передавать данные.

`TIME_WAIT` - состояние TCP-сокета после закрытия соединения. Оно нужно, чтобы:
- старые пакеты не попали в новое соединение;
- была возможность повторно отправить финальный ACK.

Почему важно для SRE:

Если приложение создает слишком много коротких соединений, может быть много `TIME_WAIT`, исчерпание ephemeral ports или нагрузка на сеть.

Команды:
```bash
ss -tan
ss -tan state time-wait
```

Короткий ответ:

Handshake нужен для установки TCP-соединения, а `TIME_WAIT` - нормальное состояние после закрытия, которое защищает от проблем со старыми пакетами.
