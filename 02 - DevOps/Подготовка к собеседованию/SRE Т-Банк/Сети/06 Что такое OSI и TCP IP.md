# Что такое OSI и TCP IP

[[00 Сети - вопросы]]

OSI - учебная модель из 7 уровней:
1. Физический.
2. Канальный.
3. Сетевой.
4. Транспортный.
5. Сеансовый.
6. Представления.
7. Прикладной.

На практике чаще используют TCP/IP-модель:
- link - Ethernet/Wi-Fi;
- internet - IP, ICMP;
- transport - TCP/UDP;
- application - HTTP, DNS, SSH.

Зачем знать уровни:

Они помогают диагностировать проблемы. Например:
- нет линка - нижние уровни;
- нет маршрута - IP/route;
- порт закрыт - транспортный уровень;
- HTTP 500 - приложение.

Короткий ответ:

OSI - модель для понимания сетевых уровней. В диагностике она помогает понять, где проблема: физика, адресация, транспорт или приложение.
