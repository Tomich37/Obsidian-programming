# Репликация и шардирование

[[00 Базы данных - вопросы]]

Репликация - это копирование данных с одной БД на другие узлы.

Зачем нужна:
- отказоустойчивость;
- чтение с реплик;
- резервирование;
- географическое распределение.

Типовая схема:
```text
Primary -> Replica 1
        -> Replica 2
```

Primary принимает запись, реплики получают копии данных.

Шардирование - это горизонтальное разделение данных по разным узлам.

Пример:
```text
users 1-1000000     -> shard 1
users 1000001-2000000 -> shard 2
```

Главная разница:
- репликация копирует одни и те же данные;
- шардирование делит разные данные между узлами.

Короткий ответ:

Репликация нужна, чтобы иметь копии данных и повысить надежность/чтение. Шардирование нужно, когда один узел уже не тянет весь объем данных или нагрузку.
