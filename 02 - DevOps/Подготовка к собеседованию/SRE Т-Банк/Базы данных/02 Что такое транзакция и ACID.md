# Что такое транзакция и ACID

[[00 Базы данных - вопросы]]

Транзакция - это набор операций с БД, который выполняется как единое целое.

Пример:

Перевод денег:
1. Списать деньги со счета A.
2. Зачислить деньги на счет B.

Нельзя выполнить только первый шаг. Или выполняются оба, или ни один.

`ACID`:
- `Atomicity` - атомарность: все операции транзакции выполняются полностью или откатываются.
- `Consistency` - согласованность: БД переходит из одного корректного состояния в другое.
- `Isolation` - изоляция: параллельные транзакции не должны ломать друг друга.
- `Durability` - долговечность: после commit данные не должны потеряться.

Команды:
```sql
-- Начинает транзакцию: следующие операции будут одной логической операцией.
-- Ожидаемо: БД перейдет в режим транзакции до COMMIT или ROLLBACK.
BEGIN;

-- Списывает 100 со счета с id = 1.
-- Ожидаемо: одна строка будет обновлена, если счет существует.
UPDATE accounts SET balance = balance - 100 WHERE id = 1;

-- Зачисляет 100 на счет с id = 2.
-- Ожидаемо: одна строка будет обновлена, если счет существует.
UPDATE accounts SET balance = balance + 100 WHERE id = 2;

-- Фиксирует оба изменения.
-- Ожидаемо: оба UPDATE станут постоянными; если до этого ошибка, нужен ROLLBACK.
COMMIT;
```

Короткий ответ:

Транзакция нужна, чтобы группа операций выполнилась надежно и целиком. ACID описывает свойства, которые делают транзакции безопасными.
