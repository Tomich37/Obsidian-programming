# Что такое nice ionice и приоритеты

[[00 Linux - вопросы]]

`nice` и `renice` управляют приоритетом процесса по CPU.

Чем больше nice-значение, тем процесс "вежливее" к другим и тем ниже его приоритет.

Примеры:
```bash
nice -n 10 command
renice 10 -p <PID>
```

`ionice` управляет приоритетом ввода-вывода.

Пример:
```bash
ionice -c2 -n7 -p <PID>
```

Когда полезно:
- тяжелый batch-процесс мешает сервису;
- бэкап активно читает диск;
- индексация или архивация забирает I/O.

Короткий ответ:

`nice` влияет на CPU-приоритет, `ionice` - на приоритет дискового ввода-вывода. Это не жесткие лимиты, а способ подсказать планировщику, кому давать ресурс раньше.
