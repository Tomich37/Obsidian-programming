# Что происходит при запуске Linux

[[00 Linux - вопросы]]

Коротко: при запуске Linux железо передает управление загрузчику, загрузчик запускает ядро, ядро инициализирует устройства и запускает первый пользовательский процесс - обычно `systemd`.

Основные этапы:
1. BIOS/UEFI проверяет железо и ищет загрузочное устройство.
2. Загрузчик, например GRUB, выбирает ядро и параметры загрузки.
3. Ядро Linux распаковывается в память и инициализирует драйверы.
4. Монтируется временная файловая система `initramfs`.
5. Ядро монтирует корневую файловую систему.
6. Запускается процесс с PID 1 - обычно `systemd`.
7. `systemd` поднимает сервисы, сеть, файловые системы и целевой режим загрузки.

Что можно сказать на собеседовании:

Linux после старта ядра переходит к пользовательскому пространству через PID 1. В современных дистрибутивах это `systemd`, который управляет дальнейшим запуском сервисов и зависимостями между ними.

Полезные команды:
```bash
# Показывает сообщения ядра с момента загрузки.
# Ожидаемо: строки про драйверы, диски, сеть, ошибки железа или ядра.
dmesg

# Показывает общее время загрузки системы и разбивку по этапам.
# Ожидаемо: время kernel, initrd, userspace и общее время старта.
systemd-analyze

# Показывает самые долгие systemd-unit'ы при загрузке.
# Ожидаемо: список сервисов с временем запуска, удобно искать тормозящий сервис.
systemd-analyze blame

# Показывает журнал текущей загрузки.
# Ожидаемо: системные логи от старта ОС до текущего момента.
journalctl -b
```
