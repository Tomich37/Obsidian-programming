# Что такое сигнал в Linux

[[00 Linux - вопросы]]

Сигнал - механизм, с помощью которого ОС или другой процесс сообщает процессу о событии.

Частые сигналы:
- `SIGTERM` - мягкая просьба завершиться;
- `SIGKILL` - принудительное завершение, перехватить нельзя;
- `SIGHUP` - часто используется для перечитывания конфига;
- `SIGINT` - прерывание с клавиатуры, обычно `Ctrl+C`;
- `SIGSTOP` - остановить процесс;
- `SIGCONT` - продолжить процесс.

Команды:
```bash
# Просит процесс корректно завершиться.
# Ожидаемо: процесс сам закрывает соединения и выходит, если обрабатывает SIGTERM.
kill -TERM <PID>

# Принудительно убивает процесс.
# Ожидаемо: процесс исчезает сразу, но graceful shutdown не выполняется.
kill -KILL <PID>

# Отправляет сигнал перечитать конфиг, если приложение это поддерживает.
# Ожидаемо: процесс остается живым, но применяет новый конфиг.
kill -HUP <PID>
```

Что сказать на собеседовании:

Обычно сначала отправляют `SIGTERM`, чтобы приложение успело корректно закрыть соединения и сохранить состояние. `SIGKILL` используют как крайний вариант, когда процесс не реагирует.
