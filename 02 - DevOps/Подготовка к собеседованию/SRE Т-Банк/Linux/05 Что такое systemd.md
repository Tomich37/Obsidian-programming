# Что такое systemd

[[00 Linux - вопросы]]

`systemd` - это система инициализации и менеджер сервисов в современных Linux. Это процесс с PID 1, который запускается после ядра и управляет остальными процессами системы.

Что делает `systemd`:
- запускает сервисы;
- следит за зависимостями между сервисами;
- управляет автозапуском;
- перезапускает сервисы при падении, если настроено;
- собирает логи через `journald`;
- управляет target'ами загрузки.

Основная сущность - `unit`. Частые типы:
- `.service` - сервис;
- `.timer` - запуск по расписанию;
- `.mount` - точка монтирования;
- `.target` - группа unit'ов.

Команды:
```bash
# Показывает текущее состояние сервиса nginx.
# Ожидаемо: active/running, failed или inactive, PID и последние логи.
systemctl status nginx

# Перезапускает nginx.
# Ожидаемо: команда без вывода при успехе, ошибки будут выведены в терминал.
systemctl restart nginx

# Включает автозапуск nginx при старте системы.
# Ожидаемо: сообщение о создании symlink или отсутствие вывода при успехе.
systemctl enable nginx

# Показывает журнал nginx из systemd-journald.
# Ожидаемо: строки логов сервиса, ошибки запуска, reload/restart.
journalctl -u nginx
```

Короткий ответ:

`systemd` - это PID 1 и менеджер сервисов. Через него удобно запускать, останавливать, диагностировать и включать автозапуск служб.
