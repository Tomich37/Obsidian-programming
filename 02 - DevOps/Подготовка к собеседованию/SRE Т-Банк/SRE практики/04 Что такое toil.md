# Что такое toil

[[00 SRE практики - вопросы]]

Toil - ручная операционная работа, которая:
- повторяется;
- не дает долгосрочной ценности;
- растет вместе с системой;
- может быть автоматизирована;
- часто выполняется вручную.

Примеры:
- вручную перезапускать сервисы;
- руками чистить диски;
- вручную заводить однотипные доступы;
- каждый раз руками выполнять одинаковый деплой.

Задача SRE - уменьшать toil через автоматизацию, self-service, улучшение мониторинга и исправление корневых причин.

Короткий ответ:

Toil - повторяющаяся ручная работа без долгосрочной пользы. SRE должен ее сокращать, иначе команда утонет в операционке.
