# Что делать если место есть но файл не создается

[[00 Файловые системы - вопросы]]

Если `df -h` показывает свободное место, но файл не создается, надо проверить не только место.

Частые причины:
- закончились inode;
- нет прав на директорию;
- файловая система смонтирована read-only;
- сработала quota;
- достигнут лимит открытых файлов;
- проблема с сетевой ФС;
- директория или путь не существуют.

Проверки:
```bash
df -h
df -i
mount | grep ' ro,'
touch testfile
ls -ld .
ulimit -n
quota -s
```

Если закончились inode:

Это значит, что создано слишком много мелких файлов. Место в гигабайтах еще есть, но новых файлов создать нельзя, потому что закончились записи inode.

Короткий ответ:

Сначала проверил бы inode через `df -i`, потом права, режим монтирования, quota и лимиты процесса. Свободное место по `df -h` не гарантирует, что файл можно создать.
