# Hardlink и symlink

[[00 Файловые системы - вопросы]]

`Hardlink` - дополнительное имя для того же inode.

Особенности hardlink:
- у исходного файла и hardlink один inode;
- оба имени равноправны;
- данные удалятся только когда удалены все hardlink;
- обычно нельзя делать hardlink на директории;
- hardlink не работает между разными файловыми системами.

`Symlink` - отдельный файл, который хранит путь к другому файлу.

Особенности symlink:
- имеет свой inode;
- может ссылаться на файл или директорию;
- может ссылаться между файловыми системами;
- может стать битым, если цель удалили или переместили.

Команды:
```bash
ln file hardlink
ln -s file symlink
ls -li
```

Короткий ответ:

Hardlink - это еще одно имя того же файла на уровне inode. Symlink - отдельный файл-указатель на путь.
