# Что такое mount и fstab

[[00 Файловые системы - вопросы]]

`mount` подключает файловую систему к директории.

Пример:
```bash
# Монтирует раздел /dev/sdb1 в директорию /data.
# Ожидаемо: после успеха содержимое раздела будет доступно через /data.
mount /dev/sdb1 /data
```

После этого содержимое раздела доступно через `/data`.

`/etc/fstab` - файл, где описано, какие файловые системы нужно монтировать автоматически при загрузке.

Пример строки:
```text
UUID=... /data ext4 defaults 0 2
```

Полезные команды:
```bash
# Показывает все текущие монтирования.
# Ожидаемо: список устройств, точек монтирования и опций.
mount

# Показывает дерево смонтированных файловых систем.
# Ожидаемо: удобная таблица TARGET, SOURCE, FSTYPE, OPTIONS.
findmnt

# Показывает блочные устройства, диски, разделы и размеры.
# Ожидаемо: дерево дисков /dev/sda, /dev/sdb, разделов и mountpoint.
lsblk

# Показывает UUID и типы файловых систем блочных устройств.
# Ожидаемо: UUID, TYPE=ext4/xfs и имена устройств.
blkid

# Пробует смонтировать все записи из /etc/fstab.
# Ожидаемо: без вывода при успехе; ошибки покажут проблемную запись fstab.
mount -a
```

Короткий ответ:

`mount` подключает файловую систему к дереву каталогов, а `fstab` описывает постоянные правила монтирования при старте системы.
