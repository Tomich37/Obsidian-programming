# Что такое mount и fstab

[[00 Файловые системы - вопросы]]

`mount` подключает файловую систему к директории.

Пример:
```bash
mount /dev/sdb1 /data
```

После этого содержимое раздела доступно через `/data`.

`/etc/fstab` - файл, где описано, какие файловые системы нужно монтировать автоматически при загрузке.

Пример строки:
```text
UUID=... /data ext4 defaults 0 2
```

Полезные команды:
```bash
mount
findmnt
lsblk
blkid
mount -a
```

Короткий ответ:

`mount` подключает файловую систему к дереву каталогов, а `fstab` описывает постоянные правила монтирования при старте системы.
