# Почему удаленный файл продолжает занимать место

[[00 Файловые системы - вопросы]]

В Linux файл удаляется из директории, но данные освобождаются только когда на файл больше нет ссылок и его никто не держит открытым.

Типичный случай:

Лог-файл удалили через `rm`, но процесс продолжает писать в открытый file descriptor. Имени файла уже нет, но место не освободилось.

Как найти:
```bash
lsof | grep deleted
```

Что делать:
- перезапустить процесс;
- заставить сервис переоткрыть лог;
- аккуратно очистить через file descriptor, если понимаешь последствия.

Короткий ответ:

Если процесс держит удаленный файл открытым, место не освободится до закрытия file descriptor. Поэтому после удаления логов иногда нужно перезапустить сервис.
