# Шифрование в покое и при передаче

[[00 Криптография - вопросы]]

Шифрование при передаче - защита данных в сети.

Примеры:
- HTTPS;
- TLS для БД;
- mTLS между сервисами;
- VPN.

Шифрование в покое - защита данных на диске или в хранилище.

Примеры:
- disk encryption;
- encrypted backups;
- encrypted object storage;
- шифрование полей в БД.

Разница:

TLS защищает данные между клиентом и сервером, но когда данные уже записаны на диск, их нужно защищать отдельно.

Короткий ответ:

In transit - шифруем данные во время передачи. At rest - шифруем данные при хранении. Для надежной защиты обычно нужны оба подхода.
