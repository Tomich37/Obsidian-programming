# Что такое JWT

[[00 Криптография - вопросы]]

`JWT` - JSON Web Token. Это компактный токен для передачи claims между сторонами.

Структура:
```text
header.payload.signature
```

В payload могут быть:
- пользователь;
- роли;
- срок действия;
- issuer;
- audience.

Важно:

JWT обычно подписан, но не обязательно зашифрован. Если используется обычный JWS, payload можно прочитать после base64url decode. Поэтому секреты в payload класть нельзя.

Что проверять:
- подпись;
- `exp`;
- `iss`;
- `aud`;
- алгоритм подписи.

Короткий ответ:

JWT - подписанный токен с данными о субъекте и правах. Он защищает целостность, но не скрывает payload, если отдельно не используется шифрование.
