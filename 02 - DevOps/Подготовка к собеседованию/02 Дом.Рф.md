## **Linux**
- `ls -lah` — список файлов с правами    
- `chmod 600 file`, `chmod 640 file`, `chmod 751 file` — права    
```
В Linux права кодируются в виде трёх чисел (октальные коды). Каждое число — это сумма:
- 4 = чтение (r)    
- 2 = запись (w)    
- 1 = выполнение (x)    

Например:
- 7 = 4+2+1 = rwx
- 6 = 4+2 = rw- 
- 4 = 4 = r-- 
- 0 = 0 = --- 

- Владелец    
- Группа    
- Остальные
```
- `top` / `htop` — процессы    
- `kill <pid>` — завершение процесса [[kill]]
- `renice 10 -p <pid>` — приоритет CPU    
- `ionice -n7 -p <pid>` — приоритет I/O    
- `ss -tulnp` — порты    
- `traceroute <host>` — маршрут    
- `telnet 10.0.0.5 6379` — проверить порт [[Диагностика сети]]
- Firewall: [[iptables]]
```bash
iptables -A INPUT -p tcp --dport 22 -j ACCEPT
iptables -A INPUT -p tcp --dport 80 -j ACCEPT
iptables -A INPUT -p tcp -j DROP
iptables-save > /etc/iptables.rules
iptables-restore < /etc/iptables.rules
```

## **Docker**
- `docker ps / docker ps -a` — контейнеры    
- `docker images` — образы    
- `docker run -d --name mycontainer nginx` — запуск    
- `docker exec -it mycontainer bash` — внутрь контейнера    
- Логи: `docker logs -f mycontainer`    
- Compose сети:
```yaml
networks:
  my_network:
    driver: bridge
```
- Compose запуск: `docker-compose up -d`    
- Postgres:
```bash
docker run -d --name my_postgres -e POSTGRES_PASSWORD=mypassword -p 5432:5432 postgres
```

## **Ansible**
- Inventory — список серверов    
- Playbook — YAML задач    
- Модули: `apt`, `yum`, `copy`, `service`    
- Примеры:
```yaml
- hosts: web
  become: yes
  tasks:
    - name: Установить Docker
      apt:
        name: docker-io
        state: present

    - name: Копировать конфиг Nginx
      copy:
        src: configure.yaml
        dest: /etc/nginx/nginx.conf
        owner: root
        group: root
        mode: '0644'

    - name: Перезапустить Nginx
      service:
        name: nginx
        state: reloaded
```
