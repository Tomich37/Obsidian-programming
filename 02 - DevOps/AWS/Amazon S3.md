# S3

[[00 AWS]]

`S3` - объектное хранилище AWS.

Основные понятия:
- bucket - контейнер для объектов;
- object - файл плюс metadata;
- key - путь/имя объекта внутри bucket;
- versioning - хранение версий объектов;
- lifecycle rules - автоматическое перемещение или удаление объектов.

Особенности:
- имя bucket глобально уникально;
- S3 не является обычной файловой системой;
- удобно хранить backup, артефакты, статические сайты, логи;
- доступы управляются IAM policy, bucket policy и ACL.

Короткий ответ:

S3 - управляемое объектное хранилище. В нем хранят не файлы в классической ФС, а объекты внутри bucket'ов.
