# AWS Security Group

[[00 AWS]]

`Security Group` - виртуальный firewall для AWS-ресурсов, например EC2 или Load Balancer.

Особенности:
- работает на уровне ENI/инстанса;
- stateful: ответный трафик разрешается автоматически;
- правила бывают inbound и outbound;
- поддерживает только allow-правила;
- deny-логика делается через отсутствие allow или через NACL.

Пример:

Разрешить входящий HTTPS `443/tcp` из интернета и SSH только из доверенной сети.

Короткий ответ:

Security Group - stateful firewall вокруг AWS-ресурса. Она разрешает только явно описанный трафик, deny-правил внутри SG нет.
