# Образ и контейнер

[[00 Docker]]

Образ - шаблон для запуска контейнера. Он содержит файловую систему, зависимости, конфигурацию и команду запуска.

Контейнер - запущенный экземпляр образа.

Простая аналогия:

Образ - как класс или установочный пакет, контейнер - конкретный работающий процесс с изоляцией.

Команды:
```bash
# Показывает локальные Docker-образы.
# Ожидаемо: repository, tag, image id, size.
docker images

# Показывает запущенные контейнеры.
# Ожидаемо: container id, image, command, status, ports, names.
docker ps

# Показывает все контейнеры, включая остановленные.
# Ожидаемо: в списке будут exited/created контейнеры.
docker ps -a
```

Короткий ответ:

Образ - неизменяемый шаблон, контейнер - запущенный экземпляр этого образа.
