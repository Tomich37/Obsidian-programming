# Dockerfile CMD ENTRYPOINT RUN

[[00 Инструкции Dockerfile]]

`RUN` выполняется во время сборки образа.

Пример:
```Dockerfile
# Выполняется при сборке образа: обновляет индекс пакетов и ставит curl.
# Ожидаемо: в образ добавится curl, при ошибке сборка остановится.
RUN apt-get update && apt-get install -y curl
```

`CMD` задает команду по умолчанию для контейнера. Ее легко переопределить при `docker run`.

`ENTRYPOINT` задает основную исполняемую команду контейнера.

Частая схема:
```Dockerfile
# Основная команда контейнера: запуск интерпретатора Python.
ENTRYPOINT ["python"]
# Аргумент по умолчанию: файл приложения, который передается в ENTRYPOINT.
CMD ["app.py"]
```

Тогда контейнер по умолчанию запустит `python app.py`.

Короткий ответ:

RUN работает при сборке образа, CMD и ENTRYPOINT - при запуске контейнера. ENTRYPOINT задает основную команду, CMD - аргументы или команду по умолчанию.
