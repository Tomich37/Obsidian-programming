# Образы и теги Docker

[[00 Docker]]

Тег — изменяемая ссылка на digest образа. `latest` не означает «самый новый проверенный»: это обычный тег, который может начать указывать на другой образ. Для воспроизводимости используют конкретную версию, а для строгой фиксации — digest.

Образ `<none>:<none>` называется dangling image. Обычно это прежний результат сборки, который потерял тег после создания новой версии. Он не обязательно опасен, но может занимать диск.

```bash
# Показывает только dangling images без тегов.
# Ожидаемо: список образов <none>:<none> или пустой вывод.
docker image ls --filter dangling=true

# Удаляет неиспользуемые dangling images после подтверждения.
# Ожидаемо: список удалённых объектов и освобождённое место.
docker image prune

# Показывает digest доступных локальных образов.
# Ожидаемо: колонка DIGEST для образов, полученных из registry с digest-метаданными.
docker image ls --digests
```
