# Ограничение ресурсов контейнера

[[00 Docker]]

Контейнер можно ограничить по CPU и памяти через cgroups.

Команды:
```bash
# Запускает контейнер с лимитом памяти 512 MB.
# Ожидаемо: контейнер не сможет использовать больше заданного лимита.
docker run --memory=512m nginx

# Запускает контейнер с ограничением CPU.
# Ожидаемо: контейнер будет использовать примерно до половины CPU.
docker run --cpus=0.5 nginx

# Показывает текущее потребление ресурсов контейнерами.
# Ожидаемо: CPU %, memory usage/limit и I/O.
docker stats
```

Что важно:

Если контейнер превысит memory limit, его может убить OOM killer. В Kubernetes это часто видно как `OOMKilled`.

Короткий ответ:

Ограничения Docker работают через cgroups. CPU можно ограничить мягче, а превышение memory limit может привести к OOM.
