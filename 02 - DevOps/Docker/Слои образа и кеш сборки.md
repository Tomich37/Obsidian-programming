# Слои образа и кеш сборки

[[00 Docker]]

Docker-образ состоит из слоев. Каждая инструкция Dockerfile вроде `RUN`, `COPY`, `ADD` обычно создает новый слой.

Кеш сборки позволяет не пересобирать неизменившиеся слои.

Best practices:
- сначала копировать файлы зависимостей;
- потом устанавливать зависимости;
- потом копировать код;
- использовать `.dockerignore`;
- объединять связанные команды;
- чистить кеш пакетного менеджера;
- не тащить лишние файлы в образ.

Короткий ответ:

Слои делают сборку переиспользуемой. Если правильно расположить инструкции Dockerfile, Docker будет чаще использовать кеш и быстрее собирать образ.
