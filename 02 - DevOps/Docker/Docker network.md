# Docker network

[[00 Docker]]

Docker network управляет сетевым взаимодействием контейнеров.

Основные типы:
- `bridge` - стандартная сеть на одном хосте;
- `host` - контейнер использует сеть хоста;
- `none` - сеть отключена;
- `overlay` - сеть между хостами, например в Swarm.

Команды:
```bash
# Показывает Docker-сети.
# Ожидаемо: bridge, host, none и пользовательские сети.
docker network ls

# Показывает детали сети и подключенные контейнеры.
# Ожидаемо: subnet, gateway, containers.
docker network inspect <network>

# Запускает nginx с пробросом порта 8080 хоста на 80 контейнера.
# Ожидаемо: сервис будет доступен на localhost:8080.
docker run -p 8080:80 nginx
```

Короткий ответ:

Docker network определяет, как контейнеры общаются между собой, с хостом и внешней сетью.
