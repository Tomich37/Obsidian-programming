# Kata Containers

[[00 Docker]]

Kata Containers запускает каждый pod или контейнер внутри лёгкой виртуальной машины. Интерфейс для оркестратора остаётся контейнерным, но изоляция ближе к VM: отдельное гостевое ядро уменьшает зависимость от общего ядра хоста.

Плюсы:
- более сильная граница изоляции для недоверенной нагрузки;
- совместимость с CRI и Kubernetes через runtime class.

Минусы:
- больший расход памяти и более медленный старт по сравнению с обычным `runc`;
- дополнительные требования к виртуализации и runtime.

Kata применяют для multi-tenant, sandbox и security-sensitive workloads. Это не замена всем обычным контейнерам, а отдельный runtime с иным компромиссом между изоляцией и накладными расходами.
