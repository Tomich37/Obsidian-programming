# Terraform lifecycle

[[Terraform]]

`lifecycle` - блок Terraform, который меняет поведение управления ресурсом.

Частые параметры:
- `prevent_destroy` - запрещает случайное удаление;
- `create_before_destroy` - сначала создать новый ресурс, потом удалить старый;
- `ignore_changes` - игнорировать изменения отдельных полей.

Пример:
```hcl
# Защищает ресурс от случайного удаления через terraform destroy/apply.
# Ожидаемо: Terraform выдаст ошибку, если план включает destroy этого ресурса.
lifecycle {
  prevent_destroy = true
}
```

Короткий ответ:

lifecycle нужен для управления рисковыми изменениями: защитить ресурс от удаления, избежать downtime при замене или игнорировать внешне управляемые поля.
