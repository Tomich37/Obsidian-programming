# Что такое tfstate

[[Terraform]]

`tfstate` - файл состояния Terraform.

Он хранит соответствие между кодом Terraform и реальными ресурсами.

Зачем нужен:
- понимать, какие ресурсы уже созданы;
- сравнивать желаемое и фактическое состояние;
- строить `plan`;
- хранить атрибуты ресурсов.

Опасности:
- state может содержать чувствительные данные;
- при потере state Terraform может потерять связь с ресурсами;
- при командной работе нужен remote backend и locking.

Команды:
```bash
# Показывает ресурсы, известные Terraform state.
# Ожидаемо: список адресов ресурсов вроде aws_instance.app.
terraform state list

# Показывает подробности ресурса из state.
# Ожидаемо: атрибуты ресурса, ID, tags и другие свойства.
terraform state show <resource>
```

Короткий ответ:

tfstate - карта между Terraform-кодом и реальной инфраструктурой. Его нужно хранить безопасно и блокировать при совместной работе.
