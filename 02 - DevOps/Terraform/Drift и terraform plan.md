# Что такое drift и terraform plan

[[Terraform]]

`Drift` - расхождение между Terraform-кодом/state и реальной инфраструктурой.

Пример:

Кто-то руками поменял security group в AWS Console. В коде этого изменения нет.

`terraform plan` помогает увидеть drift и будущие изменения.

Команды:
```bash
# Сравнивает код, state и реальные ресурсы.
# Ожидаемо: покажет, что Terraform хочет добавить, изменить или удалить.
terraform plan

# Обновляет state по реальным ресурсам без изменения инфраструктуры.
# Ожидаемо: state подтянет фактические значения из provider API.
terraform refresh
```

Короткий ответ:

Drift - ручное или внешнее изменение инфраструктуры мимо Terraform. `terraform plan` показывает, что Terraform будет делать, чтобы вернуть состояние к коду.
