### В Helm есть несколько "встроенных объектов":
- **`.Values`** → всё, что в `values.yaml`    
- **`.Release`** → метаданные релиза    
- **`.Chart`** → информация из `Chart.yaml`    
- **`.Capabilities`** → возможности кластера (версия API, поддерживаемые ресурсы и т.п.)
### Что внутри `.Release`
Когда ты делаешь:
```bash
helm install my-nginx ./myapp
```
Helm создаёт **release** с именем `my-nginx`.  
И тогда в шаблоне `.Release.Name` → `"my-nginx"`

А если поставить в другой namespace или с другим именем:
```bash
helm install staging-nginx ./myapp -n staging
```
То `.Release.Name` → `"staging-nginx"`.

### Зачем это нужно?
Чтобы **шаблоны были универсальными**.  
Например, ты один и тот же чарт `nginx` можешь ставить 10 раз в разные окружения (`prod`, `stage`, `test`), и у тебя имена ресурсов будут уникальные:
- `prod-nginx-deployment`    
- `stage-nginx-deployment`    
- `test-nginx-deployment`
