# Работа с репозиториями
```bash
helm repo add bitnami https://charts.bitnami.com/bitnami # добавить репо
helm repo list # список репозиториев
helm repo update # обновить список чартов
```
# Установка чарта
```bash
helm install <release-name> <chart> #установка чарта
helm install <release-name> <chart> -f values.yaml # установка с кастомными значениями
```
- `<release-name>` — имя релиза, который уже установлен (придуманное тобой имя релиза (например, `my-nginx`))
- `<chart>` — чарт, который применяем заново (с учётом новых values). (название чарта (например, `bitnami/nginx` или просто `nginx`, если он уже в локальном репо))
# Обновление релиза
```bash
helm upgrade <release-name> <chart> # обновление релиза
helm upgrade <release-name> <chart> -f values.yaml
```
# Просмотр и удаление
```bash
helm list # список установленных релизов
helm status <release-name> # статус релиза
helm get all <release-name> # посмотреть манифесты, которые применил helm
helm uninstall <release-name> # удалить релиз
```
# Проверка перед применением
```bash
helm template <chart> -f values.yaml # просто сгенерировать YAML ьез установки
helm diff upgrade <release-name> <chart> -f values.yaml # сравнить изменения (нужен плагин diff)
```
