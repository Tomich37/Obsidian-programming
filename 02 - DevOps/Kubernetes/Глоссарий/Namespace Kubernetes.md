# Namespace

[[00 Глоссарий]]

`Namespace` - логическое пространство имен в Kubernetes.

Зачем нужен:
- разделять окружения;
- разделять команды и проекты;
- ограничивать доступы через RBAC;
- задавать quotas;
- удобнее фильтровать ресурсы.

Стандартные namespace:
- `default` - namespace по умолчанию;
- `kube-system` - системные компоненты;
- `kube-public` - публично читаемые данные;
- `kube-node-lease` - lease-объекты node.

Команды:
```bash
# Показывает все namespace.
# Ожидаемо: список имен и статус Active/Terminating.
kubectl get ns

# Показывает pod'ы в конкретном namespace.
# Ожидаемо: ресурсы только выбранного namespace.
kubectl get pods -n <namespace>
```

Короткий ответ:

Namespace - способ логически разделить ресурсы кластера между окружениями, командами или проектами.
