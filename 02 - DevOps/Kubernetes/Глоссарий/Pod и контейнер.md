# Pod и контейнер

[[00 Глоссарий]]

Pod — минимальная сущность планирования Kubernetes. Внутри Pod может быть один или несколько контейнеров, которые:
- всегда размещаются на одной node;
- разделяют network namespace и IP;
- могут обращаться друг к другу через `localhost`;
- могут разделять volumes;
- имеют общий жизненный цикл планирования.

Контейнер — изолированный процесс с filesystem image. Pod — оболочка Kubernetes над контейнерами и общей средой их выполнения.

Один Pod не может одновременно работать на двух nodes. Для отказоустойчивости создают несколько Pod через Deployment, StatefulSet или другой controller.
