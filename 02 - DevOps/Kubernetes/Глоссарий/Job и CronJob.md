# Job и CronJob

[[00 Глоссарий]]

`Job` запускает одноразовую задачу и ждет успешного завершения pod'ов.

Примеры:
- миграция БД;
- batch-обработка;
- разовая проверка;
- импорт данных.

`CronJob` создает Job по расписанию в cron-формате.

Примеры:
- регулярный backup;
- ночная синхронизация;
- периодическая очистка.

Команды:
```bash
# Показывает Job-объекты.
# Ожидаемо: COMPLETIONS, DURATION, AGE.
kubectl get jobs

# Показывает CronJob-объекты и расписание.
# Ожидаемо: SCHEDULE, SUSPEND, ACTIVE, LAST SCHEDULE.
kubectl get cronjobs

# Показывает pod'ы, созданные job'ами.
# Ожидаемо: pod'ы со статусом Completed или Error.
kubectl get pods
```

Короткий ответ:

Job - одноразовая задача до успешного завершения, CronJob - запуск таких задач по расписанию.
