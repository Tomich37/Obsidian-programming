# BIOS и UEFI

[[00 Железо и удаленный доступ]]

`BIOS` и `UEFI` - firmware, которая стартует первой после включения сервера и передает управление загрузчику ОС.

`BIOS`:
- старый вариант firmware;
- использует MBR;
- проще по возможностям;
- имеет ограничения по разметке и загрузке.

`UEFI`:
- современная замена BIOS;
- умеет работать с GPT;
- поддерживает Secure Boot;
- хранит загрузочные записи в NVRAM;
- обычно загружает EFI-приложение с EFI System Partition.

Короткий ответ:

BIOS - старый механизм начальной загрузки, UEFI - современный. Для серверов чаще важно понимать, что UEFI работает с EFI-разделом, GPT и Secure Boot.
