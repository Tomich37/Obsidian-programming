# Как посмотреть железо сервера

[[00 Железо и удаленный доступ]]

Информацию о железе можно смотреть через системные утилиты Linux.

Команды:
```bash
# Показывает модель CPU, число ядер, потоков, архитектуру и флаги процессора.
# Ожидаемо: Model name, CPU(s), Core(s) per socket, Thread(s) per core.
lscpu

# Показывает блочные устройства: диски, разделы, размеры, точки монтирования.
# Ожидаемо: дерево устройств sda/nvme, разделы и mountpoints.
lsblk

# Показывает PCI-устройства: сетевые карты, контроллеры, видеокарты.
# Ожидаемо: список PCI-устройств с моделями и классами.
lspci

# Показывает USB-устройства.
# Ожидаемо: список подключенных USB-контроллеров и устройств.
lsusb

# Показывает DMI/SMBIOS-информацию: BIOS, материнская плата, память.
# Ожидаемо: vendor, product name, serial, BIOS version; часто нужны root-права.
dmidecode

# Показывает датчики температуры, напряжения и оборотов вентиляторов.
# Ожидаемо: температуры CPU/board, fan RPM, voltage; зависит от поддержки железа.
sensors
```

Короткий ответ:

CPU смотрю через `lscpu`, диски через `lsblk`, PCI/USB через `lspci/lsusb`, BIOS и память через `dmidecode`, датчики через `sensors`.
