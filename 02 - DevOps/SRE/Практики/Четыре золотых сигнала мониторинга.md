# Четыре золотых сигнала мониторинга

[[00 SRE практики]]

Классические четыре сигнала:
- latency - время ответа;
- traffic - объем нагрузки;
- errors - ошибки;
- saturation - насыщение ресурсов.

Примеры:
- latency: p95/p99 HTTP latency;
- traffic: RPS, QPS, messages/sec;
- errors: HTTP 5xx, failed jobs;
- saturation: CPU, memory, disk I/O, queue length, connection pool usage.

Почему это удобно:

Эти сигналы быстро показывают, что пользователю плохо и какой ресурс может быть узким местом.

Короткий ответ:

Для сервиса я бы смотрел latency, traffic, errors и saturation. Это базовый набор, который показывает и пользовательскую боль, и технические причины.
