# VFS и псевдофайловые системы

[[00 Файловые системы]]

`VFS` - Virtual File System, слой абстракции в ядре Linux.

Он позволяет приложениям одинаково работать с разными файловыми системами через общие операции:
- open;
- read;
- write;
- close;
- stat.

Псевдофайловые системы не обязательно хранят данные на диске.

Примеры:
- `/proc` - информация о процессах и ядре;
- `/sys` - информация об устройствах и драйверах;
- `/dev` - файлы устройств;
- `tmpfs` - файловая система в памяти.

Команды:
```bash
# Показывает типы смонтированных файловых систем.
# Ожидаемо: proc, sysfs, tmpfs, ext4/xfs и другие типы.
findmnt -o TARGET,FSTYPE,SOURCE

# Показывает информацию о текущем процессе через procfs.
# Ожидаемо: status-файл с PID, памятью, состоянием и другими полями.
cat /proc/self/status
```

Короткий ответ:

VFS дает единый интерфейс к разным файловым системам, а псевдофайловые системы вроде `/proc` и `/sys` показывают состояние ядра и процессов как файлы.
