# Loop devices

[[00 Файловые системы]]

Loop device представляет обычный файл как блочное устройство. Это позволяет монтировать образ диска, создать внутри него файловую систему или использовать файл в тестах LVM и шифрования.

```bash
# Находит свободный loop device и подключает к нему файл образа.
# Ожидаемо: путь вида /dev/loop0; флаг -P создаёт устройства для разделов образа.
losetup --find --show --partscan <image-file>

# Показывает активные loop devices и связанные файлы.
# Ожидаемо: таблица NAME, BACK-FILE и параметров loop-устройств.
losetup --list

# Отключает loop device после размонтирования его файловых систем.
# Ожидаемо: без вывода при успехе; устройство исчезнет из losetup --list.
losetup -d /dev/loop0
```
