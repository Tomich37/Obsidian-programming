# Диагностика дисков и разделов

[[00 Файловые системы]]

Цепочку `файл → файловая система → раздел → LVM/RAID → физический диск` удобно разбирать сверху вниз.

```bash
# Показывает дерево дисков, разделов, ФС, UUID, модели и серийные номера.
# Ожидаемо: связь mountpoint с разделом и физическим носителем.
lsblk -o NAME,TYPE,SIZE,FSTYPE,MOUNTPOINTS,MODEL,SERIAL,WWN

# Показывает источник блочного устройства для указанного пути.
# Ожидаемо: TARGET, SOURCE и FSTYPE нужной файловой системы.
findmnt -T <path>

# Показывает процессы, использующие точку монтирования или устройство.
# Ожидаемо: PID, пользователь и команда; пустой вывод означает отсутствие найденных процессов.
fuser -vm <mountpoint>

# Показывает открытые файлы внутри точки монтирования.
# Ожидаемо: процессы и конкретные пути; на большой ФС команда может работать долго.
lsof +f -- <mountpoint>

# Показывает SMART-состояние физического диска.
# Ожидаемо: модель, серийный номер, health и счётчики ошибок носителя.
smartctl -a /dev/<disk>
```

`/etc/fstab` задаёт постоянные монтирования, `/etc/mtab` обычно отражает текущие монтирования, а `/etc/mdadm/mdadm.conf` описывает сборку software RAID.
