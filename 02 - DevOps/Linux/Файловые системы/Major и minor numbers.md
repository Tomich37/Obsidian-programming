# Major и minor numbers

[[00 Файловые системы]]

У файлов устройств в Linux есть major и minor number.

`Major number` указывает, какой драйвер обслуживает устройство.

`Minor number` помогает драйверу понять, какое именно устройство используется.

Пример:
```bash
# Показывает major/minor номера устройств.
# Ожидаемо: в выводе /dev/null будут числа вроде 1, 3; первый номер major, второй minor.
ls -l /dev/null /dev/zero /dev/sda 2>/dev/null
```

Как читать:

В строке устройства вместо размера файла видны два числа:
```text
crw-rw-rw- 1 root root 1, 3 ... /dev/null
```

Здесь `1` - major, `3` - minor.

Короткий ответ:

Major выбирает драйвер устройства, minor выбирает конкретное устройство внутри этого драйвера.
