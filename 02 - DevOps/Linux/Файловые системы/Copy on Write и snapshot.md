# Что такое Copy on Write и snapshot

[[00 Файловые системы]]

`Copy on Write` означает, что при изменении данных старая версия не перезаписывается сразу. Новые данные пишутся в другое место, а метаданные переключаются на новую версию.

Зачем полезно:
- снапшоты;
- быстрые копии;
- меньше риск повредить старые данные при записи.

Snapshot - снимок состояния данных на момент времени.

Снапшоты полезны для:
- быстрых rollback;
- бэкапов;
- тестовых копий;
- защиты перед обновлениями.

Важно:

Snapshot не равен полноценному backup, если он хранится на том же диске или в той же системе.

Короткий ответ:

CoW пишет изменения в новое место, что позволяет быстро делать snapshot. Snapshot фиксирует состояние данных на момент времени, но не заменяет внешний backup.
