# Что такое inode

[[00 Файловые системы]]

`inode` - структура файловой системы, где хранится метаинформация о файле.

В inode хранится:
- тип файла;
- права;
- владелец и группа;
- размер;
- timestamps;
- количество hardlink;
- указатели на блоки данных.

Имя файла хранится не в inode, а в директории. Директория связывает имя файла с номером inode.

# Где находятся inode

На диске inode хранятся в служебных структурах конкретной файловой системы. Например, `ext4` заранее создает таблицы inode при форматировании, поэтому их количество ограничено. `XFS`, `Btrfs` и `ZFS` выделяют подобные метаданные динамически, хотя они тоже ограничены свободным пространством и внутренними лимитами.

Чаще всего inode заканчиваются на файловых системах с заранее заданным числом inode, когда создается очень много мелких файлов: кеши, очереди, сессии или неограниченно растущие каталоги. В результате свободные байты еще есть, но новые файлы и каталоги создать нельзя, пока inode не будут освобождены.

Проверка:
```bash
# Показывает файлы вместе с номером inode.
# Ожидаемо: первый столбец будет inode, одинаковый inode виден у hardlink.
ls -li

# Показывает подробные метаданные файла.
# Ожидаемо: inode, права, владелец, размер, timestamps, количество ссылок.
stat file.txt

# Показывает использование inode по файловым системам.
# Ожидаемо: IUse% покажет, не закончились ли inode.
df -i
```

Короткий ответ:

inode - это запись с метаданными файла и ссылками на его данные. Имя файла отдельно связывается с inode через директорию.
