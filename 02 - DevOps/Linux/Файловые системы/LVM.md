# Что такое LVM

[[00 Файловые системы]]

`LVM` - Logical Volume Manager, менеджер логических томов.

Он добавляет слой между физическими дисками и файловыми системами.

Основные сущности:
- `PV` - physical volume, физический диск или раздел;
- `VG` - volume group, группа физических томов;
- `LV` - logical volume, логический том, на который ставится ФС.

Зачем нужен:
- удобно расширять тома;
- объединять диски в группы;
- делать snapshot;
- гибко управлять местом.

Команды:
```bash
# Показывает physical volumes LVM.
# Ожидаемо: список дисков/разделов, входящих в LVM.
pvs

# Показывает volume groups LVM.
# Ожидаемо: имена VG, общий размер и свободное место.
vgs

# Показывает logical volumes LVM.
# Ожидаемо: имена LV, VG, размеры и атрибуты.
lvs

# Расширяет logical volume.
# Ожидаемо: размер LV увеличится, но ФС может потребовать отдельного расширения.
lvextend

# Расширяет ext2/ext3/ext4 файловую систему после увеличения тома.
# Ожидаемо: ФС начнет видеть новый размер.
resize2fs

# Расширяет XFS файловую систему.
# Ожидаемо: XFS начнет видеть новый размер, обычно команда выполняется на mountpoint.
xfs_growfs
```

Короткий ответ:

LVM позволяет гибко управлять дисковым пространством: объединять диски, создавать логические тома и расширять их без полной переделки разметки.
