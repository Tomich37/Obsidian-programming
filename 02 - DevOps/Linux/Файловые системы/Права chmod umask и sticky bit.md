# Права chmod umask sticky bit

[[00 Файловые системы]]

В Linux права задаются для:
- владельца;
- группы;
- остальных.

Биты:
- `r` = 4, чтение;
- `w` = 2, запись;
- `x` = 1, выполнение.

Пример:
```bash
# Ставит права 640 на файл.
# Ожидаемо: владелец может читать/писать, группа читать, остальные ничего.
chmod 640 file
```

Это значит:
- владелец: read/write;
- группа: read;
- остальные: нет прав.

`umask` задает права, которые будут убраны у новых файлов и директорий.

`sticky bit` на директории означает, что удалять файлы внутри может владелец файла, владелец директории или root.

Пример:
```bash
# Включает sticky bit на директории /tmp.
# Ожидаемо: в правах директории появится t, например drwxrwxrwt.
chmod +t /tmp
```

Короткий ответ:

`chmod` меняет права, `umask` задает дефолтные ограничения для новых файлов, sticky bit защищает общие директории от удаления чужих файлов.
