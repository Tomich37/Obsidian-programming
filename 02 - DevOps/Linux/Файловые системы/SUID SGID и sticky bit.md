# SUID SGID sticky bit

[[00 Файловые системы]]

`SUID` на исполняемом файле означает запуск с правами владельца файла.

Пример:

`passwd` может менять пароль пользователя, потому что ему нужны root-права для записи в системные файлы.

`SGID`:
- на исполняемом файле - запуск с правами группы файла;
- на директории - новые файлы наследуют группу директории.

`Sticky bit` на директории запрещает обычным пользователям удалять чужие файлы, даже если директория общая для записи.

Пример:
```bash
# Показывает права /tmp, где обычно установлен sticky bit.
# Ожидаемо: права вида drwxrwxrwt, буква t в конце.
ls -ld /tmp

# Ищет файлы с SUID-битом.
# Ожидаемо: список исполняемых файлов, которые запускаются с правами владельца.
find /usr/bin -perm -4000 -type f 2>/dev/null
```

Короткий ответ:

SUID и SGID меняют права выполнения файла, а sticky bit защищает общие директории от удаления чужих файлов.
