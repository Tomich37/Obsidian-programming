# Создание и восстановление файловой системы

[[00 Файловые системы]]

Файловую систему создают на разделе, LVM-томе, RAID-устройстве или другом блочном устройстве. Операция `mkfs` уничтожает прежнюю структуру данных, поэтому устройство нужно проверять особенно внимательно.

При создании задают тип ФС, label, размер блока, количество inode и другие параметры. У ext4 inode обычно резервируются при создании; XFS и Btrfs выделяют метаданные более динамично.

```bash
# Показывает устройство, тип существующей ФС, UUID и точку монтирования.
# Ожидаемо: таблица, по которой проверяют выбранное устройство до форматирования.
lsblk -f

# Создаёт ext4 с меткой data; команда удалит прежнюю структуру данных устройства.
# Ожидаемо: отчёт о superblock, inode и служебных структурах новой ФС.
mkfs.ext4 -L data /dev/<device>

# Проверяет и исправляет размонтированную ext4.
# Ожидаемо: проходы проверки и итог clean либо список исправленных ошибок.
fsck.ext4 -f /dev/<device>

# Проверяет структуру размонтированной XFS без внесения изменений.
# Ожидаемо: отчёт xfs_repair; флаг -n запрещает исправление.
xfs_repair -n /dev/<device>
```

Перед восстановлением останавливают запись, размонтируют ФС и по возможности делают образ носителя. `fsck` нельзя бездумно запускать на смонтированной файловой системе.
