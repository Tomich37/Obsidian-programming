# Блочные и символьные устройства

[[00 Файловые системы]]

В Linux устройства представлены специальными файлами, обычно в `/dev`.

`Блочные устройства` передают данные блоками.

Примеры:
- HDD;
- SSD;
- NVMe;
- разделы диска;
- loop devices.

Обычно на блочных устройствах создают разделы и файловые системы.

`Символьные устройства` передают данные потоком байтов.

Примеры:
- терминалы;
- serial port;
- `/dev/null`;
- `/dev/zero`;
- random devices.

Команды:
```bash
# Показывает блочные устройства.
# Ожидаемо: диски, разделы, размеры и точки монтирования.
lsblk

# Показывает специальные файлы устройств.
# Ожидаемо: первый символ b у блочных устройств и c у символьных.
ls -l /dev | head
```

Короткий ответ:

Блочные устройства работают с блоками данных и обычно используются для дисков. Символьные устройства работают как поток байтов.
