# Диагностика неизвестного файла и путей приложения

[[00 Диагностика Linux]]

Неизвестный файл сначала исследуют без выполнения: определяют формат, сигнатуру, печатные строки и метаданные. Если приложение не находит конфигурацию, системные вызовы показывают все проверяемые пути.

```bash
# Определяет тип данных по сигнатуре, а не только по расширению.
# Ожидаемо: текст, архив, ELF, изображение или другой распознанный формат.
file <file>

# Показывает первые байты файла в шестнадцатеричном виде.
# Ожидаемо: сигнатура формата и читаемое ASCII-представление справа.
xxd -l 64 <file>

# Извлекает печатные строки без запуска файла.
# Ожидаемо: имена библиотек, пути, сообщения или отсутствие полезного текста.
strings <file> | head

# Показывает обращения приложения к файлам и неудачные ENOENT.
# Ожидаемо: openat/stat/access с путями, где программа ищет конфигурацию.
strace -f -e trace=file <program> 2>&1 | grep -E 'ENOENT|\.conf'
```
