# Что такое iowait

[[00 Диагностика Linux]]

`iowait` - доля времени, когда CPU простаивает, потому что задачи ждут завершения операций ввода-вывода.

Важно:

iowait не означает, что CPU перегружен. Он часто показывает, что узкое место - диск, storage, сетевое хранилище или слишком медленный I/O.

Причины высокого iowait:
- медленный диск;
- перегруженный storage;
- много чтения/записи;
- проблемы с сетевой ФС;
- нехватка memory cache;
- тяжелые backup/scan/indexing процессы.

Команды:
```bash
# Показывает CPU-статистику, включая wa/iowait.
# Ожидаемо: колонка wa показывает ожидание I/O.
top

# Показывает расширенную статистику дисков.
# Ожидаемо: await, %util, r/s, w/s помогают найти перегруженный диск.
iostat -x 2 3

# Показывает процессы, которые создают дисковый I/O.
# Ожидаемо: список процессов с текущим чтением и записью.
iotop
```

Короткий ответ:

iowait - это ожидание диска или другого I/O. Если он высокий, надо смотреть не только CPU, а диски, storage и процессы, которые активно читают или пишут.
