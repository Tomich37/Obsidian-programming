В Linux почти всё логируется в `/var/log/`. Некоторые важные логи:
- `/var/log/syslog` или `/var/log/messages` — системные события.    
- `/var/log/auth.log` — логины, sudo, ssh.    
- `/var/log/nginx/` — доступ и ошибки веб-сервера.    
- `/var/log/postgresql/` — логи Postgres.

**Основные команды для анализа:**
1. **Просмотр последних строк файла:**
`tail -n 20 /var/log/syslog`

2. **Следить за логом в реальном времени:**
`tail -f /var/log/auth.log`

3. **Поиск по логу:**
`grep "error" /var/log/nginx/error.log`

4. **Комбинации:**
`grep "Failed password" /var/log/auth.log | tail -n 10`
 показывает последние 10 неудачных попыток входа.
# Логи сервисов
Если сервис управляется **systemd**, правильнее использовать `journalctl`:
```bash
sudo journalctl -u nginx -n 50
```
- `-u nginx` → лог конкретного юнита (сервиса)    
- `-n 50` → последние 50 строк    
- Можно добавить `-f` для «живого» просмотра (`tail -f`)
