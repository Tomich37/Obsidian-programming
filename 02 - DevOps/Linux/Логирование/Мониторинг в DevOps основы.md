# Prometheus + Grafana
**Prometheus** → собирает метрики (CPU, память, диски, сервисы) и хранит их.  
**Grafana** → визуализирует эти метрики в красивых графиках.

Пример метрик:
- загрузка CPU: `node_cpu_seconds_total`    
- использование памяти: `node_memory_MemAvailable_bytes`    
- работа контейнера Docker: `container_cpu_usage_seconds_total`    

**Типовой поток:**
1. Prometheus опрашивает «экспортеры» на серверах/контейнерах.    
2. Сохраняет метрики в базу данных времени.    
3. Grafana подключается к Prometheus → строит дашборды.

# ELK Stack
- **Elasticsearch** → хранение логов (очень быстрый поиск)    
- **Logstash** → сбор логов из разных источников, фильтрация, форматирование    
- **Kibana** → визуализация логов, построение графиков и дашбордов    

**Типовой поток:**
1. Логи с серверов, приложений, контейнеров → Logstash    
2. Logstash → Elasticsearch    
3. Kibana → отображает логи, ищет ошибки, строит дашборды
