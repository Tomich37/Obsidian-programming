# Диагностика
Для анализа диска используют:
- **`iostat`** — показывает использование CPU и дисков по операциям чтения/записи.    
- **`iotop`** — интерактивно показывает, какой процесс генерирует I/O в реальном времени.    
- **`free -h`** — отдельно показывает RAM и swap, чтобы понять, есть ли нехватка памяти.

Ввод
```bash
iostat -x 2 3
```

Вывод
```bash
Вывод показывает, что по диску `/dev/sda`:
- `%util = 99.5`    
- `r/s = 150`    
- `w/s = 0`
```
- **`%util`** — это процент времени, когда диск занят (занят обработкой операций чтения/записи).
    - `%util = 99.5` → диск почти полностью загружен, почти нет свободного времени для новых операций.
- **`r/s` и `w/s`** — это количество операций в секунду:    
    - `r/s` → чтения в секунду (read per second)
    - `w/s` → записи в секунду (write per second)

В нашем примере:
- `r/s = 150` → диск выполняет 150 операций чтения в секунду    
- `w/s = 0` → операций записи почти нет    
- `%util = 99.5` → почти полностью загружен чтением
# Ограничение ресурсов
Ограничивать ресурсы можно так:
1. **CPU / память**:    
	- `cpulimit` — ограничивает, сколько % CPU процесс может использовать.    
	- `nice` / `renice` — меняет приоритет процесса, чтобы другие процессы получили больше ресурсов.
2. **Диск (I/O)**:
	- `ionice` — управляет приоритетом ввода-вывода процесса    
	    - Например:    
	    `ionice -c2 -n7 -p <PID>`    
	    Здесь `-c2` = best-effort (обычный приоритет), `-n7` = низкий приоритет I/O, `-p <PID>` = PID процесса.
