# Что такое sudo

[[02 - DevOps/Linux/Общее/Общее|Общее]]

`sudo` позволяет выполнить команду с правами другого пользователя, чаще всего root.

Зачем нужно:
- не работать постоянно под root;
- выдавать точечные права;
- логировать административные действия;
- ограничивать, какие команды можно выполнять.

Конфигурация обычно лежит в `/etc/sudoers` и дополнительных файлах `/etc/sudoers.d/`.

Команды:
```bash
# Открывает sudoers через безопасный редактор с проверкой синтаксиса.
# Ожидаемо: если синтаксис сломан, visudo предупредит и не даст сохранить плохой файл.
visudo

# Выполняет команду от root.
# Ожидаемо: команда запросит пароль пользователя, если sudo требует пароль.
sudo systemctl restart nginx

# Показывает, какие sudo-права есть у текущего пользователя.
# Ожидаемо: список разрешенных команд или сообщение, что прав нет.
sudo -l
```

Короткий ответ:

sudo - механизм временного повышения прав для конкретной команды с контролем и аудитом через sudoers.
