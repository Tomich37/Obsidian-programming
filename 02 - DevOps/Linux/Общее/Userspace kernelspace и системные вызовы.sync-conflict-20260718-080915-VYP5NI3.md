# Userspace kernelspace и системные вызовы

[[02 - DevOps/Linux/Общее/Общее|Общее]]

`Userspace` - пространство пользовательских программ.

`Kernelspace` - пространство ядра Linux, где выполняются драйверы, планировщик, сеть, файловые системы и управление памятью.

Обычная программа не ходит к железу напрямую. Она просит ядро выполнить действие через системный вызов.

Примеры системных вызовов:
- `open` - открыть файл;
- `read` - прочитать;
- `write` - записать;
- `fork` - создать процесс;
- `execve` - заменить программу процесса;
- `socket` - создать сетевой сокет.

Команда:
```bash
# Показывает системные вызовы, которые делает команда ls.
# Ожидаемо: строки openat/read/write/close и другие обращения к ядру.
strace ls
```

Короткий ответ:

Userspace - обычные программы, kernelspace - ядро. Системные вызовы - контролируемый способ попросить ядро выполнить операцию с файлами, процессами, сетью или памятью.
