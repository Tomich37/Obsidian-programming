# Межпроцессное взаимодействие

[[00 Процессы Linux]]

Процессы изолированы виртуальными адресными пространствами, поэтому обмениваются данными через механизмы IPC:
- сигналы — уведомления без большого объёма данных;
- anonymous и named pipe — поток байтов;
- Unix/TCP/UDP sockets — двусторонний обмен локально или по сети;
- shared memory и `mmap` — общий участок памяти;
- message queues — очереди сообщений;
- semaphores и mutex — синхронизация доступа.

Shared memory работает быстро, потому что после настройки данные не нужно копировать через ядро при каждом обращении. Но процессы должны отдельно синхронизировать доступ.

```bash
# Показывает System V shared memory, очереди сообщений и семафоры.
# Ожидаемо: таблицы сегментов IPC или пустые секции, если они не используются.
ipcs -a

# Показывает Unix domain sockets.
# Ожидаемо: локальные сокеты процессов и их состояния.
ss -xap
```
