# Файловые дескрипторы

[[00 Процессы Linux]]

Файловый дескриптор — небольшое целое число в таблице процесса. Оно ссылается на открытое описание файла ядра, а через него — на inode, socket, pipe, устройство или другой объект.

Стандартные дескрипторы:
- `0` — stdin;
- `1` — stdout;
- `2` — stderr.

У открытого описания хранятся текущая позиция, режим и флаги. Метаданные самого файла, включая время изменения, смотрят через `stat`.

```bash
# Показывает, куда направлены дескрипторы процесса.
# Ожидаемо: символические ссылки 0, 1, 2 и другие на файлы, pipe или socket.
ls -l /proc/<PID>/fd

# Показывает открытые процессом файлы и сетевые сокеты.
# Ожидаемо: таблица COMMAND, PID, FD, TYPE и NAME.
lsof -p <PID>

# Показывает inode, права и временные метки файла.
# Ожидаемо: строки Access, Modify, Change и номер Inode.
stat <file>
```

Лимит дескрипторов проверяют через `/proc/<PID>/limits` и `ulimit -n`. Ошибка `Too many open files` обычно означает утечку дескрипторов или слишком низкий лимит.
