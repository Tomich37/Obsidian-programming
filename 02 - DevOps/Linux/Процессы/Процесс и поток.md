# Чем процесс отличается от потока

[[00 Процессы Linux]]

Процесс - это запущенная программа со своим адресным пространством, PID, правами и ресурсами.

Поток - это единица выполнения внутри процесса. Потоки одного процесса разделяют общую память процесса, но имеют свой стек и контекст выполнения.

Главное отличие:
- процессы изолированы друг от друга сильнее;
- потоки легче создавать и переключать;
- потоки быстрее обмениваются данными, потому что живут в одной памяти;
- ошибка в одном потоке может уронить весь процесс.

Пример:

Веб-сервер может быть одним процессом с несколькими потоками. Каждый поток обрабатывает отдельный запрос, но все они используют общие структуры процесса.

Как посмотреть:
```bash
# Показывает процессы в системе.
# Ожидаемо: список PID, PPID, пользователей и команд.
ps -ef

# Показывает процессы вместе с потоками.
# Ожидаемо: у одного PID может быть несколько LWP/потоков.
ps -eLf

# Показывает потоки конкретного процесса в top.
# Ожидаемо: строки потоков внутри выбранного PID и их потребление CPU.
top -H -p <PID>
```

Короткий ответ:

Процесс - отдельная изолированная программа. Поток - часть процесса, которая выполняется параллельно с другими потоками и разделяет память процесса.
