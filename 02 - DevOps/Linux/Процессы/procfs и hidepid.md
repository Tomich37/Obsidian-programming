# procfs и hidepid

[[00 Процессы Linux]]

`/proc` — виртуальная файловая система, через которую ядро публикует сведения о процессах и системе. Для PID доступны `status`, `cmdline`, `environ`, `fd`, `maps`, `limits`, `mountinfo` и другие файлы.

По умолчанию пользователи могут видеть часть информации о чужих процессах. Опция монтирования `hidepid` ограничивает доступ:
- `hidepid=1` скрывает содержимое каталогов чужих PID;
- `hidepid=2` дополнительно скрывает сами чужие PID;
- `gid=<group>` оставляет полный доступ отдельной служебной группе.

```bash
# Показывает параметры текущего монтирования procfs.
# Ожидаемо: строка /proc с типом proc и опциями, включая hidepid при его использовании.
findmnt -no TARGET,FSTYPE,OPTIONS /proc

# Показывает основную информацию о процессе из procfs.
# Ожидаемо: имя, состояние, PID, память, UID и capability процесса.
cat /proc/<PID>/status
```

Постоянную настройку `hidepid` задают в `/etc/fstab` и сначала проверяют на тестовом хосте: некоторые агенты мониторинга и диагностики должны видеть все процессы.
