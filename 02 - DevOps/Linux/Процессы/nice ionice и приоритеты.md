# Что такое nice ionice и приоритеты

[[00 Процессы Linux]]

`nice` и `renice` управляют приоритетом процесса по CPU.

Чем больше nice-значение, тем процесс "вежливее" к другим и тем ниже его приоритет.

Примеры:
```bash
# Запускает команду с пониженным CPU-приоритетом.
# Ожидаемо: команда стартует, но планировщик будет отдавать ей CPU менее охотно.
nice -n 10 command

# Меняет nice уже запущенного процесса.
# Ожидаемо: при успехе приоритет процесса изменится, проверить можно через top/ps.
renice 10 -p <PID>
```

`ionice` управляет приоритетом ввода-вывода.

Пример:
```bash
# Ставит процессу низкий приоритет дискового ввода-вывода.
# Ожидаемо: процесс продолжит работать, но будет меньше мешать другим I/O-операциям.
ionice -c2 -n7 -p <PID>
```

Когда полезно:
- тяжелый batch-процесс мешает сервису;
- бэкап активно читает диск;
- индексация или архивация забирает I/O.

Короткий ответ:

`nice` влияет на CPU-приоритет, `ionice` - на приоритет дискового ввода-вывода. Это не жесткие лимиты, а способ подсказать планировщику, кому давать ресурс раньше.
