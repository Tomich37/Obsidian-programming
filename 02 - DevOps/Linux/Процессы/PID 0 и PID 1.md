# Что такое PID 0 и PID 1

[[00 Процессы Linux]]

`PID 1` - первый процесс пользовательского пространства. В современных Linux это обычно `systemd`.

Задачи PID 1:
- запускать сервисы;
- усыновлять orphan-процессы;
- собирать статусы завершенных дочерних процессов;
- управлять состоянием системы.

`PID 0` - специальный процесс ядра, связанный с scheduler/idle. Это не обычный пользовательский процесс, который можно увидеть и управлять им как сервисом.

Команды:
```bash
# Показывает процесс с PID 1.
# Ожидаемо: systemd или init в большинстве Linux-систем.
ps -p 1 -o pid,ppid,cmd

# Показывает дерево процессов от PID 1.
# Ожидаемо: systemd/init сверху и дочерние сервисы ниже.
pstree -p 1
```

Короткий ответ:

PID 1 - главный пользовательский процесс системы, обычно systemd. PID 0 - специальная сущность ядра, связанная с планировщиком и idle.
