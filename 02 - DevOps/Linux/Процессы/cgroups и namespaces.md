# Что такое cgroups и namespaces

[[00 Процессы Linux]]

`namespaces` дают изоляцию видимости ресурсов.

Примеры:
- PID namespace - свои процессы;
- network namespace - свой сетевой стек;
- mount namespace - свои точки монтирования;
- user namespace - свои пользователи;
- UTS namespace - hostname.

`cgroups` ограничивают и учитывают ресурсы.

Через cgroups можно контролировать:
- CPU;
- память;
- I/O;
- количество процессов;
- устройства.

Почему это важно:

Контейнеры в Linux построены на namespaces и cgroups. Namespaces делают вид, что у процесса своя система, а cgroups ограничивают ресурсы.

Короткий ответ:

Namespaces отвечают за изоляцию, cgroups - за лимиты и учет ресурсов. Вместе они являются базой контейнеризации.
