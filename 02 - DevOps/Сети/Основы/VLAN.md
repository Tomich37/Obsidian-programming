# VLAN

[[00 Основы сетей]]

VLAN логически разделяет одну физическую L2-сеть на несколько broadcast domains. Кадры IEEE 802.1Q получают VLAN tag с идентификатором.

- access port передаёт трафик одного VLAN к конечному устройству обычно без тега;
- trunk port переносит несколько VLAN между коммутаторами, гипервизорами или маршрутизаторами;
- для связи между VLAN нужен L3 router или switch.

VLAN уменьшает broadcast domain и разделяет сегменты, но сам по себе не заменяет firewall и аутентификацию.

```bash
# Показывает VLAN-интерфейсы и их идентификаторы в Linux.
# Ожидаемо: интерфейсы вида eth0.100 и строка vlan protocol 802.1Q id 100.
ip -d link show type vlan
```
