# Что происходит когда открываем сайт

[[00 Основы сетей]]

Когда в браузере открываем сайт, происходит цепочка сетевых действий.

Пример:
```text
https://example.com
```

Основные шаги:
1. Браузер проверяет кеш DNS.
2. Если IP неизвестен, идет DNS-запрос.
3. Клиент получает IP-адрес сервера.
4. Устанавливается TCP-соединение.
5. Для HTTPS выполняется TLS-handshake.
6. Браузер отправляет HTTP-запрос.
7. Сервер возвращает HTTP-ответ.
8. Браузер загружает HTML, CSS, JS, картинки и отображает страницу.

Что можно добавить:

Если сайт за балансировщиком, запрос сначала придет на балансировщик или reverse proxy, например Nginx. Потом он будет отправлен на один из backend-сервисов.

Короткий ответ:

Сначала браузер узнает IP через DNS, потом устанавливает TCP-соединение, для HTTPS договаривается о шифровании через TLS, отправляет HTTP-запрос и получает ответ от сервера.
