# Что такое MTU и почему бывает проблема

[[00 Основы сетей]]

`MTU` - Maximum Transmission Unit, максимальный размер пакета, который можно передать через сетевой интерфейс без фрагментации.

Частое значение для Ethernet:
```text
1500 байт
```

Проблемы с MTU возникают, когда на пути есть туннели, VPN, overlay-сети или Kubernetes CNI. Из-за дополнительных заголовков реальный доступный размер пакета уменьшается.

Симптомы:
- маленькие запросы работают, большие зависают;
- TLS/HTTP странно обрываются;
- ping проходит, но приложение не работает;
- проблемы появляются только через VPN или overlay.

Проверки:
```bash
# Показывает параметры сетевых интерфейсов, включая MTU.
# Ожидаемо: строки интерфейсов с mtu 1500 или другим значением.
ip link

# Проверяет прохождение ICMP-пакета без фрагментации.
# Ожидаемо: reply при подходящем MTU или сообщение fragmentation needed/packet loss.
ping -M do -s 1472 <host>
```

Короткий ответ:

MTU ограничивает размер пакета. Если на пути MTU меньше ожидаемого, большие пакеты могут теряться или фрагментироваться, из-за чего приложение работает нестабильно.
