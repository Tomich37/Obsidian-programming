# Что такое IP адрес маска и шлюз

[[00 Основы сетей]]

IP-адрес - адрес хоста в сети.

Маска или CIDR-префикс показывает, какая часть IP относится к сети, а какая к конкретному хосту.

Шлюз - устройство, через которое хост отправляет трафик в другие сети.

Пример:
```text
IP:      192.168.1.10
CIDR:    /24
Сеть:    192.168.1.0
Шлюз:    192.168.1.1
```

Если адрес назначения в той же подсети, пакет отправляется напрямую. Если адрес в другой сети, пакет отправляется на шлюз.

Разница `/24` и `/16`:
- `/24` - 256 адресов, обычно 254 для хостов;
- `/16` - 65536 адресов, намного крупнее сеть.

Команды:
```bash
# Показывает IP-адреса и состояние сетевых интерфейсов.
# Ожидаемо: интерфейсы, их UP/DOWN состояние, IPv4/IPv6 адреса.
ip a

# Показывает таблицу маршрутизации.
# Ожидаемо: default route через шлюз и маршруты до локальных подсетей.
ip route
```

Короткий ответ:

IP отвечает за адрес хоста, маска определяет границы локальной сети, а шлюз нужен для выхода в другие сети.
