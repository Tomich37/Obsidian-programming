# SNI

[[00 Протоколы]]

Server Name Indication — расширение TLS ClientHello, в котором клиент передаёт имя сервера. Благодаря SNI один IP и порт 443 могут обслуживать несколько доменов с разными сертификатами.

Без SNI сервер должен выбрать сертификат до получения HTTP-заголовка `Host`, поэтому virtual hosting по HTTPS был бы ограничен.

Обычный SNI исторически передаётся открыто и виден наблюдателю сети. ECH шифрует ClientHello, но требует поддержки клиента, сервера и DNS-настроек.

```bash
# Устанавливает TLS-соединение с указанным SNI и показывает сертификат сервера.
# Ожидаемо: certificate chain для example.com и параметры TLS-сессии.
openssl s_client -connect <ip>:443 -servername example.com
```
