# Что такое HTTP и HTTPS

[[00 Протоколы]]

`HTTP` - прикладной протокол для обмена данными между клиентом и сервером.

Клиент отправляет запрос:
```http
# GET запрашивает ресурс /users у сервера example.com.
# Ожидаемо: сервер вернет список пользователей или ошибку доступа/не найдено.
GET /users HTTP/1.1
Host: example.com
```

Сервер возвращает ответ:
```http
# 200 OK означает успешную обработку запроса.
# Ожидаемо: ниже будут HTTP-заголовки и тело ответа, например JSON.
HTTP/1.1 200 OK
Content-Type: application/json
```

Основные методы:
- `GET` - получить данные;
- `POST` - создать или отправить данные;
- `PUT` - заменить ресурс;
- `PATCH` - частично обновить;
- `DELETE` - удалить.

`HTTPS` - это HTTP поверх TLS. Данные шифруются, защищаются от подмены и сервер подтверждает свою личность сертификатом.

Короткий ответ:

HTTP описывает формат запросов и ответов между клиентом и сервером. HTTPS - тот же HTTP, но защищенный TLS-шифрованием.
