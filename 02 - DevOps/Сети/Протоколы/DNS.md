# Что такое DNS

[[00 Протоколы]]

`DNS` - система доменных имен. Она преобразует доменное имя в IP-адрес.

Пример:
```text
example.com -> 93.184.216.34
```

Зачем нужен:

Людям удобно помнить имена, а компьютеры работают с IP-адресами.

Основные типы записей:
- `A` - IPv4-адрес;
- `AAAA` - IPv6-адрес;
- `CNAME` - alias на другое имя;
- `MX` - почтовые серверы;
- `TXT` - текстовые данные, часто для проверок;
- `NS` - DNS-серверы зоны.

Обычные запросы DNS используют UDP: меньше накладных расходов и не требуется устанавливать соединение. TCP используется при усечённом ответе, zone transfer и в других случаях, когда UDP недостаточно. Современный DNS также может работать поверх TLS или HTTPS.

Recursive resolver проходит цепочку root → TLD → authoritative server и возвращает клиенту конечный ответ. При нерекурсивном запросе сервер отвечает из своих данных/кеша либо возвращает referral.

Проверка:
```bash
# Запрашивает DNS-записи домена.
# Ожидаемо: ANSWER SECTION с IP-адресом, TTL и DNS-сервером.
dig example.com

# Делает простой DNS-запрос имени.
# Ожидаемо: адрес DNS-сервера и найденные IP-адреса домена.
nslookup example.com
```

Короткий ответ:

DNS - это распределенная система, которая по имени домена возвращает нужные сетевые записи, чаще всего IP-адрес сервера.
