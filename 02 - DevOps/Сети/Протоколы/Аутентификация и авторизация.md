# Аутентификация и авторизация

[[00 Протоколы]]

`Аутентификация` отвечает на вопрос: кто ты?

Примеры:
- логин и пароль;
- SSH-ключ;
- сертификат;
- одноразовый код;
- SSO.

`Авторизация` отвечает на вопрос: что тебе можно делать?

Примеры:
- роль admin/user;
- права на namespace;
- IAM policy;
- ACL.

`Basic Auth` - простой HTTP-механизм, где клиент передает `username:password`, закодированные в Base64.

Важно:

Base64 - не шифрование. Basic Auth безопасно использовать только поверх HTTPS.

Короткий ответ:

Аутентификация проверяет личность, авторизация проверяет права. Basic Auth передает учетные данные в HTTP-заголовке, поэтому без HTTPS он небезопасен.
