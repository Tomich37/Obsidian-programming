# Что такое SSH

[[00 Протоколы]]

`SSH` - защищенный протокол удаленного доступа к серверу.

Обычно работает на порту `22`.

Что дает SSH:
- удаленную консоль;
- шифрование трафика;
- аутентификацию по паролю или ключам;
- передачу файлов через `scp`/`sftp`;
- туннелирование портов.

Подключение:
```bash
# Подключается к удаленному серверу по SSH.
# Ожидаемо: запрос пароля/ключа, затем удаленная shell-сессия.
ssh user@server
```

Ключевая аутентификация:
```bash
# Генерирует пару SSH-ключей: приватный и публичный.
# Ожидаемо: файлы вроде ~/.ssh/id_ed25519 и ~/.ssh/id_ed25519.pub.
ssh-keygen

# Копирует публичный ключ на сервер в authorized_keys.
# Ожидаемо: после ввода пароля следующий вход может пройти по ключу.
ssh-copy-id user@server
```

Как объяснить просто:

SSH - это способ безопасно открыть терминал на удаленном сервере. Все команды выполняются на сервере, а трафик между клиентом и сервером шифруется.
