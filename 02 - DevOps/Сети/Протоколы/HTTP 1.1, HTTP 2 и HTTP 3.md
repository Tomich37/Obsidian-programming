# HTTP 1 1 HTTP 2 и HTTP 3

[[00 Протоколы]]

`HTTP/1.1`:
- текстовый протокол;
- один запрос за раз на соединение без pipelining на практике;
- много соединений для параллельной загрузки.

`HTTP/2`:
- бинарный протокол;
- multiplexing нескольких потоков в одном TCP-соединении;
- сжатие заголовков;
- меньше накладных расходов на множество запросов.

`HTTP/3`:
- работает поверх QUIC;
- QUIC использует UDP;
- лучше переносит потери пакетов и смену сети;
- быстрее устанавливает соединение в некоторых сценариях.

Короткий ответ:

HTTP/2 улучшил параллельность поверх одного TCP-соединения, а HTTP/3 перешел на QUIC поверх UDP, чтобы уменьшить задержки и проблемы TCP head-of-line blocking.
