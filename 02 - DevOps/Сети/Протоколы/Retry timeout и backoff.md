# Что такое Retry Timeout Backoff

[[00 Протоколы]]

`Timeout` - ограничение времени ожидания ответа.

Без timeout клиент может зависнуть надолго и держать ресурсы.

`Retry` - повтор запроса после ошибки.

Retry полезен при временных ошибках:
- сетевой сбой;
- кратковременная недоступность сервиса;
- `502`, `503`, `504`;
- rate limit, если это предусмотрено.

`Backoff` - задержка между повторами.

Часто используют exponential backoff:
```text
1s -> 2s -> 4s -> 8s
```

Важно добавлять jitter - случайный разброс, чтобы клиенты не повторяли запросы одновременно.

Короткий ответ:

Timeout ограничивает ожидание, retry повторяет временно упавшую операцию, backoff растягивает повторы во времени. Без backoff retry может усилить аварию.
