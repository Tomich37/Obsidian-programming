# Что такое ARP ICMP и DHCP

[[00 Протоколы]]

`ARP` нужен, чтобы узнать MAC-адрес по IP-адресу внутри локальной сети.

Пример:

Хост знает IP шлюза `192.168.1.1`, но для отправки Ethernet-кадра ему нужен MAC-адрес. Он отправляет ARP-запрос и получает MAC.

`ICMP` используется для служебных сетевых сообщений.

Пример:
```bash
# Отправляет ICMP echo-запросы до 8.8.8.8.
# Ожидаемо: строки reply с latency или packet loss, если доступности нет.
ping 8.8.8.8
```

`DHCP` автоматически выдает сетевые настройки:
- IP-адрес;
- маску;
- шлюз;
- DNS-серверы.

Короткий ответ:

ARP связывает IP и MAC в локальной сети, ICMP помогает диагностировать и передавать сетевые ошибки, DHCP автоматически выдает хосту сетевые настройки.
