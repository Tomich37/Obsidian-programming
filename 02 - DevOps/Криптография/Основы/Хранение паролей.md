# Как хранить пароли

[[00 Основы криптографии]]

Пароли нельзя хранить в открытом виде и нельзя просто шифровать обычным ключом.

Правильный подход - хранить результат password hashing алгоритма:
- Argon2;
- bcrypt;
- scrypt;
- PBKDF2.

Обязательно использовать `salt` - случайное значение для каждого пароля.

Зачем salt:
- одинаковые пароли получают разные хеши;
- сложнее использовать заранее подготовленные таблицы;
- усложняется массовый подбор.

Почему не обычный SHA-256:

SHA-256 слишком быстрый. Для паролей это плохо, потому что атакующий сможет очень быстро перебирать варианты. Password hashing алгоритмы специально делают вычисление дорогим.

Короткий ответ:

Пароли хранят не в открытом виде, а как salted hash через bcrypt/Argon2/scrypt. Обычные быстрые хеши для паролей не подходят.
