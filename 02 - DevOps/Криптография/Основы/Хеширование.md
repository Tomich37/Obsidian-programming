# Что такое хеширование

[[00 Основы криптографии]]

Хеширование - преобразование данных в строку фиксированной длины.

Примеры алгоритмов:
- SHA-256;
- SHA-512;
- BLAKE2.

Свойства хорошей хеш-функции:
- по хешу нельзя восстановить исходные данные;
- небольшое изменение входа сильно меняет хеш;
- сложно подобрать два разных входа с одинаковым хешем;
- одинаковый вход всегда дает одинаковый хеш.

Где используется:
- проверка целостности файлов;
- хранение паролей через специальные password hashing алгоритмы;
- цифровые подписи;
- Git хранит объекты через хеши.

Важно:

Хеширование - не шифрование. Шифрование можно расшифровать при наличии ключа, а хеш в норме необратим.

Короткий ответ:

Хеш - это необратимый отпечаток данных. Он нужен, чтобы проверить целостность или сравнить данные, не храня их в исходном виде.
