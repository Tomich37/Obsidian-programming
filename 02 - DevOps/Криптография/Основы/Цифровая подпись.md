# Что такое цифровая подпись

[[00 Основы криптографии]]

Цифровая подпись подтверждает две вещи:
- сообщение создал владелец приватного ключа;
- сообщение не изменили после подписи.

Упрощенная схема:
1. От сообщения считают хеш.
2. Хеш подписывают приватным ключом.
3. Получатель проверяет подпись публичным ключом.

Если проверка успешна, значит данные не менялись и подпись сделана соответствующим приватным ключом.

Где используется:
- TLS-сертификаты;
- подпись пакетов;
- JWT;
- электронные документы;
- Git commit signing.

Короткий ответ:

Цифровая подпись - это способ доказать авторство и целостность данных с помощью пары приватного и публичного ключа.
