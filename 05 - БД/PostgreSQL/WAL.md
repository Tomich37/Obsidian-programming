# Что такое WAL

[[PostgreSQL]]

`WAL` - Write-Ahead Log, журнал предзаписи.

Идея:

Перед изменением данных БД сначала записывает информацию об изменении в журнал. Если сервер упадет, БД сможет восстановить согласованное состояние по WAL.

Зачем нужен WAL:
- восстановление после сбоя;
- репликация;
- point-in-time recovery;
- надежный commit.

Пример для PostgreSQL:

PostgreSQL пишет изменения в WAL, а потом уже данные попадают в файлы таблиц. Реплики могут получать WAL и воспроизводить изменения у себя.

Короткий ответ:

WAL - журнал изменений БД, который пишется до изменения основных данных. Он нужен для надежности, восстановления и репликации.
