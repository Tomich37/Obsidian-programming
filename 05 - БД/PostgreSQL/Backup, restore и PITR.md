# Backup restore PITR

[[PostgreSQL]]

Backup - резервная копия данных.

Restore - восстановление из резервной копии.

`PITR` - Point-In-Time Recovery, восстановление на конкретный момент времени.

Зачем PITR:

Если в 12:10 случайно удалили таблицу, можно восстановиться на 12:09, а не только на время последнего полного бэкапа.

Для PostgreSQL PITR обычно требует:
- base backup;
- архив WAL;
- настройку восстановления до нужного времени.

Важный SRE-момент:

Бэкап, который ни разу не проверяли восстановлением, нельзя считать надежным.

Короткий ответ:

Backup нужен для копии данных, restore - для восстановления, PITR - для восстановления на конкретный момент времени с помощью бэкапа и WAL.
