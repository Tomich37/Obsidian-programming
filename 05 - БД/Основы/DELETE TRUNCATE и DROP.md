# DELETE, TRUNCATE и DROP

[[00 Основы баз данных]]

- `DELETE` удаляет строки, поддерживает `WHERE`, обычно журналирует изменения построчно и запускает соответствующие triggers.
- `TRUNCATE` быстро удаляет все строки таблицы, не поддерживает `WHERE`, обычно требует более сильную блокировку и по-разному взаимодействует с identity/sequence в разных СУБД.
- `DROP` удаляет сам объект вместе с его структурой и данными.

Транзакционность и точное поведение зависят от СУБД. В PostgreSQL все три операции можно откатить внутри незавершённой транзакции, но блокировки и стоимость отличаются.

```sql
-- Удаляет только неактивных пользователей.
-- Ожидаемо: число удалённых строк; таблица и остальные строки сохранятся.
DELETE FROM users WHERE active = false;

-- Удаляет все строки таблицы и сбрасывает связанные identity в PostgreSQL.
-- Ожидаемо: пустая таблица с сохранённой структурой.
TRUNCATE TABLE users RESTART IDENTITY;

-- Удаляет таблицу как объект.
-- Ожидаемо: таблица users перестанет существовать.
DROP TABLE users;
```
