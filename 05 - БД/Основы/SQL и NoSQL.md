# SQL и NoSQL

[[00 Основы баз данных]]

`SQL`-БД обычно хранят данные в таблицах со схемой и используют SQL для запросов.

Примеры:
- PostgreSQL;
- MySQL;
- Oracle;
- MS SQL Server.

Сильные стороны SQL:
- строгая схема;
- транзакции;
- связи между таблицами;
- сложные запросы;
- хорошая согласованность.

`NoSQL` - общий класс БД, где модель данных не обязательно табличная.

Примеры:
- key-value: Redis;
- document: MongoDB;
- wide-column: Cassandra;
- graph: Neo4j.

Когда NoSQL может быть удобен:
- гибкая схема;
- очень большие объемы;
- высокая горизонтальная масштабируемость;
- специфичная модель данных.

Короткий ответ:

SQL удобен для структурированных данных, транзакций и сложных связей. NoSQL выбирают, когда важнее гибкость модели, масштабирование или специальный тип доступа к данным.
